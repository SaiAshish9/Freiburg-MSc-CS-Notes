# Multi-Layer Perceptrons (MLPs) – Deep Learning

## 1. What is an MLP?

A **Multi-Layer Perceptron (MLP)** is a type of artificial neural network consisting of multiple layers of interconnected neurons. It is also known as a **Feedforward Neural Network**.

An MLP learns patterns and relationships from input data to make predictions.

### Architecture of an MLP

An MLP typically consists of three types of layers:

1. **Input Layer:** Receives the input features.
2. **Hidden Layers:** Learn patterns and relationships from the input data.
3. **Output Layer:** Produces the final prediction.

### Example: Credit Card Default Prediction

Suppose we want to predict whether a customer will default on a credit card payment.

Input features could include:

- Age
- Income
- Credit limit
- Previous payment history
- Outstanding balance

The MLP processes these features and produces a prediction:

- `0` → No default
- `1` → Default

---

## 2. How Does an MLP Neuron Work?

Each neuron performs three main operations:

1. Receives input values.
2. Calculates a weighted sum and adds a bias.
3. Applies an activation function.

### Mathematical Representation

The weighted sum is:

$$  
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b  
$$

The activation function is then applied:

$$  
a = f(z)  
$$

Where:

- $x_i$ = Input features
- $w_i$ = Weights
- $b$ = Bias
- $f$ = Activation function
- $a$ = Neuron output    

---

## 3. Activation Functions

Activation functions introduce **non-linearity** into neural networks, allowing them to learn complex patterns.

### A. ReLU (Rectified Linear Unit)

$$  
f(x) = \max(0,x)  
$$

- Returns 0 for negative inputs.
- Returns the input itself for positive inputs.
- Commonly used in hidden layers.    

### B. Sigmoid

$$  
f(x) = \frac{1}{1+e^{-x}}  
$$

- Produces values between 0 and 1.
- Commonly used in the output layer for binary classification.    

### C. Tanh (Hyperbolic Tangent)

$$  
f(x) = \tanh(x)  
$$

- Produces values between -1 and 1.
- Often used in neural network architectures where zero-centered outputs are useful.

## 4. How Does an MLP Learn?

MLPs generally learn through two important processes:

### A. Forward Propagation

Forward propagation passes input data through the network to generate predictions.

Steps:

1. Input data enters the network.
2. Each neuron calculates its weighted sum.
3. Activation functions are applied.
4. Information moves through the hidden layers.
5. The output layer produces the final prediction.

### B. Backpropagation

Backpropagation calculates how much each weight contributes to the prediction error.

Steps:

1. Compare the predicted output with the actual target.
2. Calculate the loss (prediction error).
3. Calculate gradients using the chain rule.
4. Update weights and biases using an optimization algorithm.    

### Weight Update Equation

$$  
w_{\text{new}} = w_{\text{old}} -  
\eta \frac{\partial L}{\partial w}  
$$

Where:

- $\eta$ = Learning rate
- $L$ = Loss function
- $\frac{\partial L}{\partial w}$ = Gradient of the loss with respect to the weight    

**Common optimizers:** Gradient Descent, Stochastic Gradient Descent (SGD), and Adam.

| Characteristic       | Description                     |
| -------------------- | ------------------------------- |

| Connectivity         | Fully connected layers          |
| Direction            | Feedforward (forward only)      |
| Learning             | Backpropagation                 |

| Applications         | Classification and Regression   |

---

## 6. MLP vs. Single-Layer Perceptron

| Single-Layer Perceptron           | Multi-Layer Perceptron                  |
| --------------------------------- | --------------------------------------- |
| No hidden layer                   | One or more hidden layers               |
| Learns linear decision boundaries | Can learn nonlinear decision boundaries |
| Simpler architecture              | More complex architecture               |
| Cannot solve XOR problem          | Can solve XOR problem                   |
Backpropagation is not exclusive to networks with hidden layers. It can also be applied to a single-layer neural network.

### Important Concept

An MLP with nonlinear activation functions can approximate complex nonlinear functions.

Without nonlinear activation functions, stacking multiple linear layers is mathematically equivalent to a single linear transformation.

---

## 7. Key Takeaways

- MLP stands for Multi-Layer Perceptron.
- It is a type of feedforward neural network.
- It consists of input, hidden and output layers.
- Neurons calculate weighted sums and apply activation functions.
- Activation functions introduce non-linearity.
- Forward propagation generates predictions.
- Backpropagation calculates gradients and helps update weights.
- Optimizers such as SGD and Adam minimize the loss function.
- MLPs are used for classification and regression tasks.

**Remember:**

MLP = Multiple Layers + Neurons + Weights + Biases + Activation Functions + Backpropagation.
