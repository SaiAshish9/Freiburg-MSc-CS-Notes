## 1. Definition

**Deep Learning (DL)** is a subset of **Machine Learning (ML)** that uses artificial neural networks with multiple layers to learn complex patterns from data and make predictions.

### Relationship

- **Artificial Intelligence (AI)** → Machines performing tasks that require human intelligence.
- **Machine Learning (ML)** → Machines learning patterns from data.
- **Deep Learning (DL)** → Machines learning complex representations using multilayer neural networks.

$$
\text{Deep Learning} \subset \text{Machine Learning} \subset \text{Artificial Intelligence}
$$

---

## 2. How Deep Learning Works

A deep neural network consists of three main types of layers:

1. **Input Layer**
   - Receives input features such as images, text, or numerical values.

2. **Hidden Layers**
   - Process information using weights, biases, and activation functions.
   - Learn increasingly complex representations of the input.

3. **Output Layer**
   - Produces the final prediction or classification.

### Example: Cat Image Classification

- **Input:** Image of a cat
- **Early Layers:** Detect edges and textures
- **Intermediate Layers:** Identify shapes and patterns
- **Later Layers:** Recognize higher-level features
- **Output:** Cat (95% probability)

## 3. Mathematical Representation

A single artificial neuron computes:

$$
z = \sum_{i=1}^{n} w_i x_i + b
$$

The activation function produces:

$$
a = f(z)
$$

Where:

- $x_i$ = Input features
- $w_i$ = Weights
- $b$ = Bias
- $z$ = Weighted sum
- $f$ = Activation function
- $a$ = Neuron output

### Multiple Layers

For layer $l$:

$$
z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}
$$

$$
a^{(l)} = f^{(l)}(z^{(l)})
$$

Where $a^{(0)} = x$ represents the input.

## 4. Training a Deep Learning Model

1. **Forward Propagation**
   - Input data passes through the network.
   - The network generates predictions.

2. **Loss Calculation**
   - Measures the difference between predictions and actual values.

3. **Backpropagation**
   - Calculates gradients of the loss with respect to model parameters.

4. **Optimization**
   - Updates weights and biases to reduce the loss.

### Gradient Descent

$$
w_{\text{new}} = w_{\text{old}} - \eta \frac{\partial L}{\partial w}
$$

Where:

- $\eta$ = Learning rate
- $L$ = Loss function
- $\frac{\partial L}{\partial w}$ = Gradient of loss with respect to weight

## 5. Machine Learning vs Deep Learning

| Machine Learning | Deep Learning |
|---|---|
| Often requires manual feature engineering | Automatically learns feature representations |
| Can work well with smaller datasets | Often benefits from large datasets |
| Includes SVM, decision trees, regression | Includes CNN, RNN, Transformers |
| Often requires less computational power | Often requires greater computational power |
| Many models are easier to interpret | Complex networks can be harder to interpret |

## 6. Types of Deep Learning Architectures

| Architecture | Applications |
|---|---|
| ANN / MLP | Classification, regression |
| CNN | Image recognition, computer vision |
| RNN | Sequential data |
| LSTM | Time-series prediction |
| Transformer | NLP, LLMs, computer vision |
| Autoencoder | Dimensionality reduction, anomaly detection |
| GAN | Synthetic image generation |

## 7. Applications

- **Computer Vision:** Image classification, object detection
- **Natural Language Processing:** Translation, chatbots
- **Speech Recognition:** Speech-to-text systems
- **Healthcare:** Medical image analysis
- **Autonomous Driving:** Object and lane detection
- **Recommendation Systems:** Personalized recommendations

---

## 8. Key Takeaways

- Deep Learning is a subset of Machine Learning.
- It uses neural networks with multiple layers.
- Hidden layers learn complex feature representations.
- Forward propagation generates predictions.
- Loss functions measure prediction errors.
- Backpropagation computes gradients.
- Optimizers update parameters to minimize loss.
- Common architectures include CNNs, RNNs, and Transformers.
