## From Logistic Regression to the Perceptron

### Diagram Explanation

The diagram illustrates how **Logistic Regression** translates directly into a single-layer **Perceptron** (artificial neuron) architecture:

  

1. **Input Phase ($\mathbf{x}$):** Takes input features $\mathbf{x} = [x_1, x_2, x_3]^T$.
2. **Linear Combination ($z$):** Computes the weighted linear sum plus bias:$$z = \mathbf{w}^T \mathbf{x} + b = \sum_{i} w_i x_i + b$$
3. **Activation Function ($h$):** Passes $z$ through a non-linear logistic (sigmoid) activation function to output a continuous prediction probability between $0$ and $1$:$$h(z) = \frac{1}{1 + e^{-z}}$$
### Questions & Short Solutions

#### **1. Forward Pass as a Succession of Two Formulas**

> _Write down the forward pass of a perceptron as a succession of two formulas._
> 
>   

1. **Linear combination:**$$z = \mathbf{w}^T \mathbf{x} + b$$
2. **Non-linear activation:**$$h = \sigma(z) = \frac{1}{1 + e^{-z}}$$

#### **2. Computational Complexity of Cross-Entropy Loss**

> _What is the computational complexity (in big-O notation) of computing the cross-entropy loss for a perceptron on a dataset of $N$ data points with $d$ dimensions?_
- **Complexity:** **$\mathcal{O}(N \cdot d)$**

**Short breakdown:**

- Matrix multiplication $\mathbf{X}\mathbf{w}$ for $N$ instances with $d$ features takes $\mathcal{O}(N \cdot d)$ operations.
- Applying sigmoid activation and evaluating cross-entropy loss takes $\mathcal{O}(N)$ operations.
- Total forward pass cost is dominated by $\mathcal{O}(N \cdot d)$.
