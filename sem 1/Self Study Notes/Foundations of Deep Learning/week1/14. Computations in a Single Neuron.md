
A single neuron performs two simple steps of computation: 

x1w1 + x2w2 + x3w3 -> z | a -> 

1. Compute a weighted sum of the inputs: z = x1w1 + x2w2 + x3w3 
2. Perform a nonlinear transformation: a = h(z)

activation from previous layer, each of them multiplied by weights and then we take the weighted sum of these inputs.

The second step is to perform non linear transformation of this weighted sum.

It's imp. that transformation is nonlinear, because this weighted sum here, actually a linear operation. 

We could use many neurons as we want, we could use very wide layers, very deep layers, parallel computation of diff. and so on.

If each of them is a linear fn, then combination of linear functions would still be a linear fn and we wouldn't able to express a non linear function.

For simple non linear transformations, we can express complex non linear functions, and learn.

Information Flow in Fully-Connected Neural Nets – Forward Pass

Pictures => Classification

Input pixels are just numbers, multiplied by set of weights and happens in parallel to compute the activation in the next layer

Activated is multiplied by weights, so on and so forth and we arrive at the output layer

Output layer depicts probability distribution over possible classes (right-side)  given fixed set of weights between diff. layers

Optimise ind. weights by gradient descent and we compute gradients of overall loss fn

Loss fn takes probabilistic classification and compares it to the true label of the image

Then we take derivates of this loss fn that judges how similar out classification is to the true label and work backwards to actually calculate gradient of this loss fn

Inputs => Layers => Classification

Computing Gradients in Fully-Connected Neural Nets – Backward Pass

This flow backward to the type of weight that we want to compute the gradient with respect to weight,  where we flow information backwards to compute it for all the weights in the neural weight (we can do it for one but less useful)


Then we pass resulting gradients to optimizer that then does stochastic gradient steps

We've forward path flowing from inputs to outputs to compute probabilistic predictions and backward path to compute gradients of the loss fn with respect to any of the weights

If we want for one, we can stop at right side. For all, pass it across the network

Loss functions (Classification + True Label) => Layers => Gradients
