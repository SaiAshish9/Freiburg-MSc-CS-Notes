# Flexibility of Deep Learning: Example Tasks

- **Classification:** $\text{input } \mathbb{R}^n \rightarrow \text{categories}$ (e.g., $\{\text{cat}, \text{dog}, \text{human}\}$)
- **Regression:** $\text{input } \mathbb{R}^n \rightarrow \mathbb{R}$ (e.g., house prices)

- **Structured output prediction:** $\text{structured output (vector, graph, etc.)}$
  - **Pixel-wise segmentation:** $\text{image} \rightarrow \text{image}$
  - **Machine translation:** $\text{sequence} \rightarrow \text{sequence}$
  - **Parsing:** $\text{text} \rightarrow \text{tree whose nodes are verbs, nouns, adverbs, etc.}$
  - **Image captioning:** $\text{image} \rightarrow \text{sentence}$
  - **Denoising:** $\text{corrupted example } \tilde{x} \in \mathbb{R}^n \rightarrow \text{clean example } x \in \mathbb{R}^n$
