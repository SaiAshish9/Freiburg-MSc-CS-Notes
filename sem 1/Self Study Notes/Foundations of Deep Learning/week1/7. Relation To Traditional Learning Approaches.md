
### A. Rule-based Systems

- **Flow:** $\text{Input} \rightarrow \text{Hand-designed program} \rightarrow \text{Output}$
- **Description:** Humans write down explicit rules and logic manually. No machine learning takes place.

### B. Classic Machine Learning

- **Flow:** $\text{Input} \rightarrow \text{Hand-designed features} \rightarrow \text{Mapping from features} \rightarrow \text{Output}$
- **Description:** Requires substantial human effort in **feature engineering** (converting raw data into a form suitable for simple classifiers). Only the final mapping/classification layer is learned from data.

### C. Representation Learning

- **Flow:** $\text{Input} \rightarrow \text{Features} \rightarrow \text{Mapping from features} \rightarrow \text{Output}$
- **Description:** The system automatically discovers the representations/features needed for the task, reducing the burden of manual feature engineering.

### D. Deep Learning

- **Flow:** $\text{Input} \rightarrow \text{Simple Features} \rightarrow \text{Abstract Features (Multiple Layers)} \rightarrow \text{Mapping} \rightarrow \text{Output}$
- **Description:** Extends representation learning by stacking multiple layers. Lower layers learn simple features (e.g., edges in images), while deeper layers combine them into highly abstract representations (e.g., shapes, object parts).
