
In shallow learning, we would have a relatively shallow neural network.

For example in page 22, we would just have a single hidden layer to learn a representation that makes it easier to learn the classification in the final layer.


In contrast,

Deep learning has a a hierarchy of representations that build on each other, from simple to complex. 

Features are learned in an end-to-end fashion, from raw data

Slightly higher level of abstraction for example we can take the edges and combine them to contours

We can take contours and combine them to object parts


We can use these high level features (object parts) to actually learn a classifier on top


Pixels => Edges => Contours => Object Parts => Classes

Each of these images actually represents the input that would most excite this neuron.
