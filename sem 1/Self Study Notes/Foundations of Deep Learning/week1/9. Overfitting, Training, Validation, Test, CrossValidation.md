- Overfitting: When a model learns training data too closely, including noise, and performs poorly on unseen data.
- Training Set: Data used to train the model and learn its parameters (weights).
- Validation Set: Data used to evaluate the model during development and select hyperparameters.
- Test Set: Unseen data used to evaluate the final model's generalization performance.
- Cross-Validation: A technique that splits data into multiple folds, repeatedly training and validating on different subsets to obtain a more reliable performance estimate.
- Hyperparameter Tuning: The process of finding the best model settings (e.g., learning rate, batch size, number of layers) using validation performance.

### Quick Comparison

|Concept|Purpose|
|---|---|
|Training|Learn model parameters|
|Validation|Select and tune the model|
|Testing|Evaluate final performance|
|Cross-Validation|Evaluate across multiple data splits|
|Hyperparameter Tuning|Optimize model settings|
|Overfitting|Model memorizes rather than generalizes|

Remember: Training = Learning, Validation = Tuning, Testing = Final Evaluation.
