How the loss changes with the weight


## 1. What do the computed gradients represent?

- **Direction of Steepest Ascent:** Mathematically, the gradient vector points in the direction where the loss function increases most rapidly with respect to the model's parameters (weights and biases).
- **Sensitivity / Rate of Change:** Each partial derivative in the gradient vector indicates how sensitive the loss function is to a small perturbation in a specific parameter. A larger absolute value means a small adjustment to that weight will result in a significant change in the loss.

## 2. Why do we have to compute the gradients?

- **Parameter Optimization:** Training a neural network involves minimizing a loss function. Since we cannot solve for optimal weights analytically in complex non-linear architectures, we use iterative optimization algorithms (such as Gradient Descent or SGD).
- **Directional Updates:** The gradients tell the optimizer **which direction and how aggressively** to update each weight (e.g., $w \leftarrow w - \eta \nabla L$) to systematically reduce the error and improve model performance over time.
