# Linear Layer Backpropagation & Memory Requirements

## 1. Questions on Activation Functions & Derivatives

### Examples of Activation Functions
* **ReLU (Rectified Linear Unit):** $\text{ReLU}(x) = \max(0, x)$
  * Fast computation, avoids vanishing gradients for positive inputs; prone to "dying ReLU" for non-positive inputs.
* **Sigmoid (Logistic):** $\sigma(x) = \frac{1}{1 + e^{-x}}$
  * Maps inputs to $(0, 1)$, historically used for binary classification outputs; susceptible to vanishing gradients.
* **Tanh (Hyperbolic Tangent):** $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
  * Zero-centered mapping to $(-1, 1)$, often preferred over Sigmoid in hidden layers.
* **Leaky ReLU / PReLU:** $\text{Leaky ReLU}(x) = \max(\alpha x, x)$ where $\alpha \approx 0.01$
  * Fixes dying ReLU by maintaining a small non-zero slope for negative inputs.
* **Softmax:** $\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$
  * Converts logits into a normalized probability distribution across multiple classes.

### Purpose of Non-Linear Activation Functions
* **Universal Approximation:** Without non-linear functions, stacked linear layers collapse mathematically into a single linear transformation ($W_2 W_1 x = W_{net} x$).
* **Complex Feature Learning:** Non-linearities allow neural networks to learn intricate, non-linear decision boundaries and hierarchical data representations.

### Key Activation Derivatives
* **ReLU Derivative:**
  $$\frac{d}{dx} \text{ReLU}(x) = \begin{cases} 0 & \text{if } x < 0 \\ 1 & \text{if } x > 0 \end{cases}$$
  *(Conventionally assigned $0$ or $1$ at $x=0$.)*

* **Sigmoid Derivative:**
  $$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$

## 2. Questions on Gradients

* **What Computed Gradients Represent:**
  * **Direction of Steepest Ascent:** The gradient vector $\nabla_{\theta} L$ points in the direction of maximum increase of the loss function $L$ with respect to parameters $\theta$.
  * **Sensitivity / Rate of Change:** Each element $\frac{\partial L}{\partial w_i}$ measures how sensitive the total loss is to a small change in weight $w_i$.

* **Why We Compute Gradients:**
  * Necessary for iterative optimization algorithms (such as SGD, Adam) to update weights ($w \leftarrow w - \eta \nabla L$) and minimize model error during training.

## 3. Theoretical Memory Calculation & Optimization

### Setup & Numerical Specs
* Batch Size: $N = 64$
* Input/Output Dimensions: $M = D = 4096$
* Precision: **32-bit floating point (FP32)** $\rightarrow 4 \text{ bytes per scalar}$

### A. Explicit Jacobian Storage Memory ($\frac{\partial Y}{\partial X}$)
The full Jacobian matrix/tensor $\frac{\partial Y}{\partial X}$ maps every output element in $Y \in \mathbb{R}^{N \times M}$ to every input element in $X \in \mathbb{R}^{N \times D}$, resulting in a shape of $(N \times M \times N \times D)$.

$$\text{Total Elements} = N \cdot M \cdot N \cdot D = 64 \times 4096 \times 64 \times 4096 = 68,719,476,736 \text{ elements}$$

$$\text{Memory} = 68,719,476,736 \times 4 \text{ bytes} = 274,877,906,944 \text{ bytes} \approx \mathbf{256\text{ GB} \text{ (or } 274.88\text{ GB)}}$$

> **Conclusion:** Storing full explicit Jacobian tensors per layer is completely intractable in deep learning.

### B. Standard Layer Memory (Weights vs. Saved Activations)
* **Weight Matrix $W$ ($D \times M = 4096 \times 4096$):**
  $$4096 \times 4096 \times 4 \text{ bytes} = 67,108,864 \text{ bytes} \approx \mathbf{67.11\text{ MB}}$$
* **Saved Input Activations $X$ ($N \times D = 64 \times 4096$):**
  $$64 \times 4096 \times 4 \text{ bytes} = 1,048,576 \text{ bytes} = \mathbf{1.00\text{ MB}}$$

---

### How to Avoid Storing Excessive Data

1. **Implicit Vector-Jacobian Products (VJPs):** Never store full Jacobian matrices. Compute gradient updates directly using matrix multiplication ($\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} W^T$ and $\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y}$).
2. **Activation Checkpointing (Gradient Checkpointing):** Store activations only at selected checkpoint layers during the forward pass and recompute intermediate activations on-the-fly during backprop.
3. **Mixed Precision Training:** Use 16-bit precision (FP16/BF16) or FP8 to halve or quarter activation and parameter memory requirements.
4. **Activation Quantization & Offloading:** Compress stored activation tensors or temporarily offload them to CPU RAM during execution.
