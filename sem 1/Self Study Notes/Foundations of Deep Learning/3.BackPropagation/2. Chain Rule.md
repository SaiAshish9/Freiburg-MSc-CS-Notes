## 1. What is the derivative of the ReLU activation function?

- **ReLU Definition:**    $$\text{ReLU}(x) = \max(0, x) = \begin{cases} 0 & \text{if } x < 0 \\ x & \text{if } x \ge 0 \end{cases}$$
- **Derivative:**    $$\frac{d}{dx} \text{ReLU}(x) = \begin{cases} 0 & \text{if } x < 0 \\ 1 & \text{if } x > 0 \end{cases}$$
    _(Note: The derivative is technically undefined at $x = 0$, but in practice, it is conventionally assigned a value of $0$ or $1$ at $0$.)_

## 2. What is the derivative of the logistic sigmoid activation function?

- **Sigmoid Definition:**$$\sigma(x) = \frac{1}{1 + e^{-x}}$$
- **Derivative:** The derivative of the sigmoid function can be expressed compactly in terms of the function itself:    $$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$
- **Derivation Steps (for reference):**
    1. Write $\sigma(x) = (1 + e^{-x})^{-1}$
    2. Apply the chain rule: $\sigma'(x) = -1(1 + e^{-x})^{-2} \cdot (-e^{-x}) = \frac{e^{-x}}{(1 + e^{-x})^2}$        
    3. Rewrite as: $\left(\frac{1}{1 + e^{-x}}\right) \left(\frac{e^{-x}}{1 + e^{-x}}\right) = \sigma(x) (1 - \sigma(x))$
