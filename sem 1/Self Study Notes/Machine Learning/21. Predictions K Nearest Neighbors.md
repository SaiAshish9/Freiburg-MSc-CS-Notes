KNN predicts the target value of a new input by aggregating the target values of its \(k\) nearest neighbors.

If the three nearest house prices are €200k, €220k and €240k:

f(x) = (200 + 220 + 240)/3 = €220K


**1. Regression (Continuous Target)**

Calculates the average of the nearest neighbors' target values.

$$
f(x)=\frac{1}{k}\sum_{y'\in y_x^{(\text{nearest})}}y'
$$

**2. Classification (Nominal Target)**

Calculates the proportion of neighbors belonging to class $c$.

$$
f(x)_c=\frac{1}{k}\left|\{y'\in y_x^{(\text{nearest})}:y'=c\}\right|
$$

**Where:**
- $k$ = Number of nearest neighbors
- $y_x^{(\text{nearest})}$ = Target values of the nearest neighbors
- $f(x)$ = Predicted continuous value
- $f(x)_c$ = Proportion of neighbors belonging to class $c$

**Key Takeaway:**
- **Regression:** Average of target values.
- **Classification:** Majority vote based on class proportions.
