
Softmax is a function used in multi-class classification to convert model outputs (scores or logits) into probabilities for multiple classes.

For example, classifying an image as a Cat, Dog, or Bird
- **One-hot encoding:** Correct class = 1, other classes = 0.
- **Softmax:** Converts class scores into probabilities that sum to 1.
$$\hat y_{n,c}=\frac{e^{f(x_n;\theta_c)}}{\sum_{q=1}^{C}e^{f(x_n;\theta_q)}}$$
- **Categorical Cross-Entropy:** Measures the error between true labels and predicted probabilities.
$$\mathcal L(y_{n,:},\hat y_{n,:})=-\sum_{c=1}^{C}y_{n,c}\log(\hat y_{n,c})$$
- **Goal:** Minimize loss by assigning high probability to the correct class.


Example: If the correct class is Dog:

| Class | Target |
| ----- | ------ |
| Cat   | 0      |
| Dog   | 1      |
| Bird  | 0      |
