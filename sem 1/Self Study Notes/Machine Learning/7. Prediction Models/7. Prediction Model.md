

## Estimating the Target Variable

- Given training data of **N recorded instances**, composed of:
    - **Feature variables:** X ∈ ℝᴺˣᴹ
    - **Target variable:** y ∈ ℝᴺ
        
- **Goal:** Predict the target variable of a future instance:
    - x^test ∈ ℝᴹ
        
- We need a function **f(x)** that predicts the target:
    - **ŷ := f(x)**
    - This function is known as a **Prediction Model**.

### How to Find a Good Prediction Function?

- Parameterize the function using learnable parameters **θ (theta)**:
    - **f(x; θ)**
- Learn the parameters **θ** using the training data.
