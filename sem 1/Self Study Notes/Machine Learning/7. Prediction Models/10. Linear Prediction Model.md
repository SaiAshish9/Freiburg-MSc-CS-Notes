
## Linear Model
$$\hat{y}_n = \theta_0 + \theta_1 x_{n,1} + \theta_2 x_{n,2} + \dots + \theta_M x_{n,M} = \theta_0 + \sum_{m=1}^{M} \theta_m x_{n,m}$$

- **$\hat{y}_n$**: Predicted output for sample $n$
- **$\theta_0$**: Bias term / intercept
- **$\theta_m$**: Weight for feature $m$
- **$x_{n,m}$**: Feature $m$ for sample $n$

Example: Predicting house prices
