
## Machine Learning: Data, Prediction Model, Loss, and Regularization

### 1. Data Dimensions

We have **N instances (samples)**, each containing **M features**.
- **X ∈ ℝᴺˣᴹ** = Input dataset (feature matrix).
- **y ∈ ℝᴺ** = Target values (ground truth).
- **N** = Number of training samples.
- **M** = Number of features per sample.
    

**Example:**

- 100 students (N = 100).
- 5 features per student (M = 5), such as age, attendance, and grades.
- Each student has one target value, such as their final exam score.

### 2. Prediction Model

A prediction model uses input features and learnable parameters to predict an output.

**f: ℝᴹ × ℝᴷ → ℝ**

**ŷₙ = f(xₙ; θ)**

- **f** = Prediction function (model).
- **xₙ ∈ ℝᴹ** = Features of the nth sample.
- **θ ∈ ℝᴷ** = Learnable model parameters.
- **K** = Number of model parameters.
- **ŷₙ** = Predicted target value for the nth sample.

**Example:** Predicting a student's exam score using attendance and previous grades.

The model learns parameters θ to make accurate predictions.

### 3. Loss Function

A loss function measures the difference between the predicted value and the actual value.

**ℒ(yₙ, ŷₙ): ℝ × ℝ → ℝ**
- **ℒ** = Loss function.
- **yₙ** = Actual target value.
- **ŷₙ** = Predicted target value.
- **ℝ × ℝ → ℝ** = Takes two real numbers and returns one real number.

**Example:**
- Actual exam score = 90.
- Predicted exam score = 85.
- Squared Error = (90 − 85)² = 25.

**Goal:** Minimize the loss to improve prediction accuracy.

### 4. Regularization

Regularization helps prevent **overfitting**, where a model performs well on training data but poorly on new data.

**Ω(θ): ℝᴷ → ℝ**
- **Ω** = Regularization function.
- **θ** = Model parameters.
- **ℝᴷ → ℝ** = Takes K parameters and returns one numerical value.

**Purpose:**
- Penalizes overly complex models.
- Encourages simpler parameter values.
- Helps improve predictions on unseen data.

**Example:** L1 (Lasso) and L2 (Ridge) regularization.

### 5. Objective Function

The objective function combines prediction errors and regularization to find the best model parameters.

__θ_ = arg min_θ [Σₙ₌₁ᴺ ℒ(yₙ, ŷₙ) + Ω(θ)]_*

**Explanation:**
- **θ*** = Optimal model parameters.
- **arg min_θ** = Find the values of θ that minimize the objective.
- **Σₙ₌₁ᴺ** = Sum over all N training samples.
- **ℒ(yₙ, ŷₙ)** = Prediction error for each sample.
- **Ω(θ)** = Regularization penalty.

**Goal:** Find parameters θ that:
1. Minimize prediction errors.
2. Avoid unnecessary model complexity.
3. Generalize well to unseen data.

### 6. Summary

| Concept   | Meaning                                   |
| --------- | ----------------------------------------- |
| N         | Number of training samples                |
| M         | Number of features per sample             |
| K         | Number of learnable parameters            |
| X         | Input feature matrix                      |
| y         | Actual target values                      |
| θ         | Learnable model parameters                |
| f(xₙ; θ)  | Prediction model                          |
| ŷₙ        | Predicted target value                    |
| ℒ(yₙ, ŷₙ) | Loss function measuring prediction error  |
| Ω(θ)      | Regularization penalty                    |
| arg min   | Finds parameters minimizing the objective |

**In short:** Machine learning trains a prediction model **f(x; θ)** by finding parameters **θ** that minimize prediction errors while controlling model complexity through regularization.
