## Supervised Learning Example: Credit Card Default Prediction

**Goal:** Predict whether a new bank customer will default on their credit card payment using data from existing customers.

### 1. Understanding the Notation

**X ∈ ℝᴺˣ²³**

- **X** = Input dataset (feature matrix).
- **N** = Number of existing bank customers.
- **23** = Number of features collected for each customer.
- **ℝ** = Set of real numbers.
    

**y ∈ {0, 1}ᴺ**
- **y** = Ground truth (correct answers).
- **0** = Customer does not default.
- **1** = Customer defaults.
- **N** = One answer for each existing customer.
    

### 2. Understanding the 23 Features

| Feature    | Description                                                           |
| ---------- | --------------------------------------------------------------------- |
| x[:,1]     | Credit limit (NT dollars)                                             |
| x[:,2]     | Gender (1 = male; 2 = female)                                         |
| x[:,3]     | Education (1 = graduate; 2 = university; 3 = high school; 4 = others) |
| x[:,4]     | Marital status (1 = married; 2 = single; 3 = others)                  |
| x[:,5]     | Age (years)                                                           |
| x[:,6:11]  | Past payment delays (-1 = paid duly; 1–9 = months of delay)           |
| x[:,12:17] | Previous bill amounts (6 features)                                    |
| x[:,18:23] | Previous payment amounts (6 features)                                 |

**Note:** The colon `:` means all rows. For example, x[:,1] represents the first feature (credit limit) for all customers. The feature ranges use mathematical indexing, starting from 1.

### 3. Example Dataset

| Customer | Credit Limit | Gender | Age | ... | Default (y) |
| -------- | ------------ | ------ | --- | --- | ----------- |
| 1        | 20,000       | 1      | 24  | ... | 1           |
| 2        | 120,000      | 2      | 26  | ... | 0           |
| 3        | 90,000       | 2      | 34  | ... | 0           |
| ...      | ...          | ...    | ... | ... | ...         |
| N        | 50,000       | 1      | 30  | ... | 1           |

The machine learning model learns relationships between the 23 features and whether customers defaulted.

### 4. Predicting a New Customer

**x[N+1, :] ∈ ℝ²³**

This means:
- **N+1** = A new customer who was not part of the training dataset.
- **:** = All 23 features of that customer.
- **ℝ²³** = A vector containing 23 numerical values.    

We want to predict:

**ŷₙ₊₁ ∈ {0, 1}**

**Prediction Flow:**

New Customer (23 features: age, credit limit, payment history, etc.)
↓
Trained ML Classification Model
↓
**Predicted Result:**
- **0** = No Default
- **1** = Default

### 5. Which Type of Machine Learning?

This is **Supervised Learning → Binary Classification** because:
- **Supervised:** We train using existing customers with known outcomes (y).
- **Binary:** Only two possible classes (0 or 1).
- **Classification:** We predict a category rather than a continuous number.

**In short:** Learn from N existing customers, each with 23 features and a known default outcome, to predict whether customer N+1 will default.
