### Exhaustive Search of Decision Splits

#### 1. Candidate Split Thresholds ($V^{(j)}$)
For numerical feature $j$, candidate thresholds $V^{(j)}$ are the **mid-points between consecutive unique values** of that feature.

* **Why mid-points?** Any split threshold strictly between two adjacent sorted unique values produces the exact same left/right partition; the mid-point is the standard representative.
* **Categorical features:** Can be mapped to numerical values so they fit into the same threshold-splitting formulation.

---

#### 2. Example from the Slide
Given $\mathcal{D} \in (\mathbb{N}^2 \times \{0, 1\})^N$ with $N = 5$ samples $((x^{(1)}, x^{(2)}), y)$:

$$\mathcal{D} := \{((1, 5), 1),\ ((3, 4), 0),\ ((1, 6), 1),\ ((5, 5), 1),\ ((4, 8), 1)\}$$

* **Feature $1$ ($j = 1$):** Unique sorted values are $1, 3, 4, 5$, giving mid-points:
  $$V^{(1)} = \{2,\ 3.5,\ 4.5\}$$
* **Feature $2$ ($j = 2$):** Unique sorted values are $4, 5, 6, 8$, giving mid-points:
  $$V^{(2)} = \{4.5,\ 5.5,\ 7\}$$

---

#### 3. Optimal Split Objective
Across $M$ features and candidate thresholds $v \in V^{(j)}$, exhaustive search selects the split $x_{:, j} \le v$ that maximizes purity gain $\text{I}(x_{:, j} \le v)$:

$$\underset{\substack{j \in \{1, \dots, M\} \\ v \in V^{(j)}}}{\arg\max}\ \text{I}(x_{:, j} \le v)$$

* $x_{:, j}$ represents the $j$-th feature across all data points in the node being split.
* Every $(j, v)$ pair is tested by splitting the node's subset into $\mathcal{D}^{(\text{L})}$ and $\mathcal{D}^{(\text{R})}$ and computing the resulting purity gain.

---

#### 4. Runtime Complexity
* **Naive runtime:** $\mathcal{O}(N^2 M)$ for a single node split.
  * There are $M$ features and up to $\mathcal{O}(N)$ candidate mid-points per feature, yielding $\mathcal{O}(NM)$ candidate splits.
  * Evaluating each split naively over $N$ samples costs $\mathcal{O}(N)$, resulting in $\mathcal{O}(N^2 M)$ total operations.
* **Practical speedup:** Sorting feature values once per node ($\mathcal{O}(MN \log N)$) and maintaining running/incremental sufficient statistics across sorted candidate splits lowers split evaluation time.

---

### Worked Example: Exhaustive Search for the Best Split

Using the dataset from the slide $\mathcal{D} \in (\mathbb{N}^2 \times \{0, 1\})^N$ with $N = 5$ samples $((x^{(1)}, x^{(2)}), y)$:

| Sample $i$ | Feature 1 ($x_i^{(1)}$) | Feature 2 ($x_i^{(2)}$) | Label ($y_i$) |
| :---: | :---: | :---: | :---: |
| $1$ | $1$ | $5$ | $1$ |
| $2$ | $3$ | $4$ | $0$ |
| $3$ | $1$ | $6$ | $1$ |
| $4$ | $5$ | $5$ | $1$ |
| $5$ | $4$ | $8$ | $1$ |

Here, $M = 2$ features, $|\mathcal{D}| = 5$, with $4$ samples of class $1$ and $1$ sample of class $0$.

---

#### 1. Candidate Split Sets
* **Feature $1$ ($j = 1$):** Sorted unique values $\{1, 3, 4, 5\} \implies V^{(1)} = \{2,\ 3.5,\ 4.5\}$.
* **Feature $2$ ($j = 2$):** Sorted unique values $\{4, 5, 6, 8\} \implies V^{(2)} = \{4.5,\ 5.5,\ 7\}$.
* Total candidate splits evaluated: $3 + 3 = 6$ splits.

---

#### 2. Impurity Before Split (Gini Impurity)
For a subset $S$ with class proportions $p_0, p_1$, define impurity as $\text{H}(S) = 1 - (p_0^2 + p_1^2)$:

* In $\mathcal{D}$: $p_0 = \frac{1}{5} = 0.2$, $p_1 = \frac{4}{5} = 0.8$.
* $\text{H}(\mathcal{D}) = 1 - (0.2^2 + 0.8^2) = 1 - (0.04 + 0.64) = 0.32$.
* Weighted impurity before split: $|\mathcal{D}| \cdot \text{H}(\mathcal{D}) = 5 \times 0.32 = 1.60$.

---

#### 3. Evaluating Candidate Splits via Purity Gain
Recall the gain in purity:

$$\text{I}(x_{:, j} \le v) = |\mathcal{D}| \cdot \text{H}(\mathcal{D}) - \left(|\mathcal{D}^{(\text{L})}| \cdot \text{H}\left(\mathcal{D}^{(\text{L})}\right) + |\mathcal{D}^{(\text{R})}| \cdot \text{H}\left(\mathcal{D}^{(\text{R})}\right)\right)$$

##### Test Split A: Feature 1 at $x_{:, 1} \le 2$ ($j = 1, v = 2$)
* $\mathcal{D}^{(\text{L})}$ (samples with $x^{(1)} \le 2$): $\{((1, 5), 1), ((1, 6), 1)\}$, $|\mathcal{D}^{(\text{L})}| = 2$.
  * Classes: $2$ of class $1$, $0$ of class $0 \implies \text{H}(\mathcal{D}^{(\text{L})}) = 1 - (0^2 + 1^2) = 0$.
* $\mathcal{D}^{(\text{R})}$ (samples with $x^{(1)} > 2$): $\{((3, 4), 0), ((5, 5), 1), ((4, 8), 1)\}$, $|\mathcal{D}^{(\text{R})}| = 3$.
  * Classes: $1$ of class $0$ ($p_0 = \frac{1}{3}$), $2$ of class $1$ ($p_1 = \frac{2}{3}$).
  * $\text{H}(\mathcal{D}^{(\text{R})}) = 1 - \left(\left(\frac{1}{3}\right)^2 + \left(\frac{2}{3}\right)^2\right) = 1 - \frac{5}{9} = \frac{4}{9} \approx 0.444$.
* Post-split weighted impurity: $(2 \times 0) + \left(3 \times \frac{4}{9}\right) = \frac{4}{3} \approx 1.333$.
* **Purity gain:** $\text{I}(x_{:, 1} \le 2) = 1.60 - 1.333 = +0.267$.

##### Test Split B: Feature 2 at $x_{:, 2} \le 4.5$ ($j = 2, v = 4.5$)
* $\mathcal{D}^{(\text{L})}$ (samples with $x^{(2)} \le 4.5$): $\{((3, 4), 0)\}$, $|\mathcal{D}^{(\text{L})}| = 1$.
  * Classes: $1$ of class $0$, $0$ of class $1 \implies \text{H}(\mathcal{D}^{(\text{L})}) = 0$.
* $\mathcal{D}^{(\text{R})}$ (samples with $x^{(2)} > 4.5$): $\{((1, 5), 1), ((1, 6), 1), ((5, 5), 1), ((4, 8), 1)\}$, $|\mathcal{D}^{(\text{R})}| = 4$.
  * Classes: $0$ of class $0$, $4$ of class $1 \implies \text{H}(\mathcal{D}^{(\text{R})}) = 0$.
* Post-split weighted impurity: $(1 \times 0) + (4 \times 0) = 0$.
* **Purity gain:** $\text{I}(x_{:, 2} \le 4.5) = 1.60 - 0 = +1.60$.

---

#### 4. Optimal Split Selection
Comparing candidate splits, $x_{:, 2} \le 4.5$ yields the largest purity gain ($\text{I} = 1.60$), separating the single class-$0$ sample into $\mathcal{D}^{(\text{L})}$ and all four class-$1$ samples into $\mathcal{D}^{(\text{R})}$:

$$\underset{\substack{j \in \{1, 2\} \\ v \in V^{(j)}}}{\arg\max}\ \text{I}(x_{:, j} \le v) = (j = 2,\ v = 4.5)$$
