### CART — Train Decision Tree (`Algorithm 1`)

**CART** (Classification and Regression Trees) recursively constructs a binary decision or regression tree from the root node down to leaf nodes.

#### Inputs & Hyperparameters
* **Data parameters:** Subset of training samples $\mathcal{D} := \{(x_i, y_i)\}_{i=1}^{|\mathcal{D}|}$ reaching node $n$ and current depth $\ell$.
* **Hyperparameters:**
  * $L$ (**Max Depth**): Maximum tree depth allowed.
  * $\delta$ (**Min Instances for Split**): Minimum number of instances required in $\mathcal{D}$ to perform a split.

---

#### Algorithm Walkthrough
1. **Split Eligibility Check (Line 1):** Evaluates $|\mathcal{D}| > \delta \land \ell \le L$. A node splits only if it has strictly more than $\delta$ samples **and** its depth $\ell$ is within $L$.
2. **Best Split Search (Line 2):** Calls `SearchSplit(D)` to find feature column $x_{:, j}$ and threshold $v$ maximizing purity gain.
3. **Decision Node Assignment (Line 3):** Sets node $n$ to test $(x_{:, j} \le v,\ \text{yes/no?})$.
4. **Left Sub-tree Recursion (Lines 4–5):** Partitions $\mathcal{D}^{(\text{L})} := \{(x, y) \in \mathcal{D} \mid x_{:, j} \le v\}$ and calls `CART(D^{(L)}, n_{left}, \ell + 1)`.
5. **Right Sub-tree Recursion (Lines 6–7):** Partitions $\mathcal{D}^{(\text{R})} := \{(x, y) \in \mathcal{D} \mid x_{:, j} > v\}$ and calls `CART(D^{(R)}, n_{right}, \ell + 1)`.
6. **Leaf Node Creation (Lines 8–9):** If $|\mathcal{D}| > \delta \land \ell \le L$ does not hold, node $n$ becomes a **leaf** with prediction $\hat{y} = \text{aggregate}(\pi_y(\mathcal{D}))$ (where $\pi_y(\mathcal{D})$ projects the target labels $y$ of $\mathcal{D}$):
   * **Regression:** typically the mean of $y$ in $\mathcal{D}$.
   * **Classification:** typically the majority class (or class distribution) of $y$ in $\mathcal{D}$.

* **Initial Call:** Starts at depth $\ell = 1$ with `CART(D, n_{root}, 1)`.
