## Decision Tree & Regression Tree Splits

### 1. Tree Prediction Model
For a decision/regression tree with parameters $\theta = \langle R_1, \dots, R_J, \hat{y}^{(R_1)}, \dots, \hat{y}^{(R_J)} \rangle$, the prediction is:

$$f(x; \theta) = \sum_{j=1}^{J} \hat{y}^{(R_j)} \cdot \mathbb{1}(x \in R_j)$$

#### Indicator Function
The indicator function $\mathbb{1}(\cdot)$ maps a logical statement or condition $a$ to $1$ if true ($\top$), and $0$ otherwise:

$$\mathbb{1}(a) := \begin{cases} 1 & \text{if } a = \top \\ 0 & \text{otherwise} \end{cases}$$

* **Role in trees:** Acts as a binary selector across disjoint leaf regions $R_1, \dots, R_J$, zeroing out all regions except the one containing $x$ so that $f(x; \theta) = \hat{y}^{(R_k)}$.
* **Optimization implication:** Non-differentiable step behavior ($0$ derivative almost everywhere, undefined at boundaries), requiring greedy splitting rather than direct gradient descent.

---

### 2. Intuition on Splits: Regression
Regression trees select the split point that minimizes the total **Residual Sum of Squares (RSS)** across the resulting left and right regions:

$$\text{Total RSS} = \text{RSS}_{\text{left}} + \text{RSS}_{\text{right}}$$

| Split | Left RSS (Red) | Right RSS (Blue) | Total RSS |
| :--- | :--- | :--- | :--- |
| **(black)** | $0.652$ | $0.835$ | **$1.487$** |
| **(orange)** | $5.22$ | $0.429$ | $5.649$ |
| **(red)** | $6.46$ | $0.175$ | $6.635$ |
| **(blue)** | $6.54$ | $0.094$ | $6.634$ |

* **Optimal choice:** **(black)** achieves the lowest Total RSS ($1.487$) by isolating the steep initial drop ($y \approx 1.0$) into its own left region.
* **Suboptimal splits:** Moving the threshold further right (**orange**, **red**, **blue**) forces the left region to average both the initial peak and the subsequent trough ($y \approx -0.3$), inflating $\text{RSS}_{\text{left}}$ above $5.2$.

### Splits That Maximize Purity

#### 1. Dataset Partitioning via a Split
Given a dataset $\mathcal{D} := \{(x_i, y_i)\}_{i=1}^{N} \in (\mathcal{X} \times \mathcal{Y})^N$, a threshold split $x \le v$ partitions $\mathcal{D}$ into two disjoint subsets (left and right child nodes):

$$\mathcal{D}^{(\text{L})} := \{(x, y) \in \mathcal{D} \mid x \le v\} \quad \text{and} \quad \mathcal{D}^{(\text{R})} := \{(x, y) \in \mathcal{D} \mid x > v\}$$

* **Left child $\mathcal{D}^{(\text{L})}$:** Contains all data points whose feature value satisfies $x \le v$.
* **Right child $\mathcal{D}^{(\text{R})}$:** Contains all remaining data points where $x > v$.
* **Partition property:** $\mathcal{D}^{(\text{L})} \cap \mathcal{D}^{(\text{R})} = \emptyset$ and $|\mathcal{D}^{(\text{L})}| + |\mathcal{D}^{(\text{R})}| = |\mathcal{D}| = N$.

---

#### 2. Impurity Function
The **impurity** of a dataset $\mathcal{D}$ is measured by a function $\text{H}(\mathcal{D}) : (\mathcal{X} \times \mathcal{Y})^{|\mathcal{D}|} \to \mathbb{R}_+$.

* **Non-negativity:** $\text{H}(\mathcal{D}) \ge 0$.
* **Interpretation:** Lower impurity means targets/labels within the subset are more homogeneous ("purer"); higher impurity means greater mixing/spread.

---

#### 3. Gain in Purity (Information Gain / Split Criterion)
The optimal split $x \le v$ is chosen to **maximize** the **gain in purity** $\text{I}(x \le v)$:

$$\text{I}(x \le v) = \underbrace{|\mathcal{D}| \cdot \text{H}(\mathcal{D})}_{\text{Impurity before split}} - \underbrace{\left(|\mathcal{D}^{(\text{L})}| \cdot \text{H}\left(\mathcal{D}^{(\text{L})}\right) + |\mathcal{D}^{(\text{R})}| \cdot \text{H}\left(\mathcal{D}^{(\text{R})}\right)\right)}_{\text{Impurity after split}}$$

* **First term ($|\mathcal{D}| \cdot \text{H}(\mathcal{D})$):** Total unnormalized impurity of the parent node before splitting.
* **Second term ($|\mathcal{D}^{(\text{L})}| \cdot \text{H}(\mathcal{D}^{(\text{L})}) + |\mathcal{D}^{(\text{R})}| \cdot \text{H}(\mathcal{D}^{(\text{R})})$):** Sum of impurities across both child nodes, each weighted by its sample count $|\mathcal{D}^{(\text{L})}|$ or $|\mathcal{D}^{(\text{R})}|$.
* **Maximizing $\text{I}(x \le v)$:** Equivalent to minimizing the post-split weighted impurity $|\mathcal{D}^{(\text{L})}| \cdot \text{H}(\mathcal{D}^{(\text{L})}) + |\mathcal{D}^{(\text{R})}| \cdot \text{H}(\mathcal{D}^{(\text{R})})$, since $|\mathcal{D}| \cdot \text{H}(\mathcal{D})$ is constant for a given node.

---

### Worked Example: Purity Gain on a Split

Suppose we have a dataset $\mathcal{D}$ with $N = 6$ samples $(x_i, y_i)$, where $x_i \in \mathbb{R}$ is a feature and $y_i \in \{0, 1\}$ is a binary class label:

| Sample $i$ | Feature $x_i$ | Label $y_i$ |
| :---: | :---: | :---: |
| $1$ | $1.0$ | $0$ |
| $2$ | $2.0$ | $0$ |
| $3$ | $3.0$ | $1$ |
| $4$ | $5.0$ | $0$ |
| $5$ | $6.0$ | $1$ |
| $6$ | $7.0$ | $1$ |

Here, $|\mathcal{D}| = 6$, with $3$ samples of class $1$ and $3$ samples of class $0$.

---

#### 1. Choice of Impurity Function $\text{H}(\mathcal{D})$
Using **Gini impurity** for a subset $S$ with fraction $p_1$ of class $1$ and $p_0 = 1 - p_1$ of class $0$:

$$\text{H}(S) = 1 - (p_0^2 + p_1^2)$$

* **Before split ($\mathcal{D}$):** $p_0 = \frac{3}{6} = 0.5$, $p_1 = \frac{3}{6} = 0.5$, so:
  $$\text{H}(\mathcal{D}) = 1 - (0.5^2 + 0.5^2) = 0.5$$
* **Weighted impurity before split:**
  $$|\mathcal{D}| \cdot \text{H}(\mathcal{D}) = 6 \times 0.5 = 3.0$$

---

#### 2. Evaluating Candidate Split $x \le 2.5$
The split $x \le 2.5$ partitions $\mathcal{D}$ into:

$$\mathcal{D}^{(\text{L})} = \{(1.0, 0), (2.0, 0)\}, \quad |\mathcal{D}^{(\text{L})}| = 2$$

$$\mathcal{D}^{(\text{R})} = \{(3.0, 1), (5.0, 0), (6.0, 1), (7.0, 1)\}, \quad |\mathcal{D}^{(\text{R})}| = 4$$

* **Left subset $\mathcal{D}^{(\text{L})}$:** $p_0 = \frac{2}{2} = 1.0$, $p_1 = 0.0$
  $$\text{H}\left(\mathcal{D}^{(\text{L})}\right) = 1 - (1.0^2 + 0.0^2) = 0.0 \quad \text{(completely pure)}$$
* **Right subset $\mathcal{D}^{(\text{R})}$:** $p_0 = \frac{1}{4} = 0.25$, $p_1 = \frac{3}{4} = 0.75$
  $$\text{H}\left(\mathcal{D}^{(\text{R})}\right) = 1 - (0.25^2 + 0.75^2) = 1 - (0.0625 + 0.5625) = 0.375$$
* **Weighted impurity after split:**
  $$|\mathcal{D}^{(\text{L})}| \cdot \text{H}\left(\mathcal{D}^{(\text{L})}\right) + |\mathcal{D}^{(\text{R})}| \cdot \text{H}\left(\mathcal{D}^{(\text{R})}\right) = (2 \times 0.0) + (4 \times 0.375) = 0 + 1.5 = 1.5$$

---

#### 3. Gain in Purity $\text{I}(x \le 2.5)$
Applying the purity gain formula:

$$\text{I}(x \le 2.5) = \underbrace{3.0}_{\text{before split}} - \underbrace{1.5}_{\text{after split}} = 1.5$$

* **Takeaway:** Because $\text{I}(x \le 2.5) = 1.5 > 0$, splitting at $x \le 2.5$ reduces total weighted impurity from $3.0$ to $1.5$, making the resulting child nodes purer overall.
