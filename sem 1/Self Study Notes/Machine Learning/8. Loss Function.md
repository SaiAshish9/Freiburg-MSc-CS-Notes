
## Difference to Ground Truth

- The quality of a prediction model **f(x; θ)** is measured by the difference between:
    
    - **ŷ** = Estimated (predicted) target.
    - **y** = Ground-truth (actual) target.
        
- This difference is evaluated using a **Loss Function**:
    
    **ℒ(y, ŷ): ℝ × ℝ → ℝ**
    
- **Loss Function:** Measures how different the predicted value is from the actual value.
    
- The term **loss** is generally used for minimization tasks, such as regression.
    - **Minimization:** Lower loss indicates better predictions.
    - **Maximization:** In some tasks, the objective function ℒ(y, ŷ) needs to be maximized instead.
