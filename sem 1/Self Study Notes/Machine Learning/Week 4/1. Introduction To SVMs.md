
# Support Vector Machines (SVMs)

https://ai.kuleuven.be/aivooriedereen/en/support-vector-machines


## 1. Definition

- Support Vector Machine (SVM) is a **supervised machine learning algorithm** primarily used for classification and also for regression.
- Its main objective is to find the optimal decision boundary (hyperplane) that separates data points belonging to different classes.
- SVM tries to maximize the margin between the two classes.

## 2. Important Concepts

### Hyperplane

- A decision boundary that separates different classes.
- In 2D, it is a line; in 3D, it is a plane; in higher dimensions, it is called a hyperplane.

Equation:

`wᵀx + b = 0`

Where:

- `w` = Weight vector
- `x` = Input feature vector
- `b` = Bias

### Margin

- The distance between the decision boundary and the closest data points from each class.
- SVM aims to maximize this margin.
- A larger margin generally improves generalization.

`Margin = 2 / ||w||`

### Support Vectors

- Data points closest to the decision boundary.
- They determine the position and orientation of the optimal hyperplane.
- Removing or changing support vectors can change the decision boundary.

## 3. Mathematical Formulation (Hard Margin SVM)

Objective function:

`Minimize: (1/2) ||w||²`

Subject to:

`yᵢ(wᵀxᵢ + b) ≥ 1`

Where:

- `xᵢ` = Input data point
- `yᵢ ∈ {-1, +1}` = Class label
- `w` = Weight vector
- `b` = Bias

Why minimize `||w||²`?

- Maximizing the margin is equivalent to minimizing the squared norm of the weight vector.
- Margin width = `2 / ||w||`.

## 4. Hard Margin vs Soft Margin SVM

### Hard Margin SVM

- Requires perfect separation of classes.
- Does not allow misclassification.
- Suitable for linearly separable datasets.
- Sensitive to outliers.

### Soft Margin SVM

- Allows some classification errors.
- Works with overlapping datasets.
- Introduces slack variables (ξᵢ).
- Uses regularization parameter C to control the trade-off between margin size and classification errors.

Soft-margin objective:

`Minimize: (1/2)||w||² + C Σ ξᵢ`

Subject to:
`yᵢ(wᵀxᵢ + b) ≥ 1 - ξᵢ`
`ξᵢ ≥ 0`

### Effect of C

- Large C: Penalizes misclassification heavily; narrower margin may result.
- Small C: Allows more misclassification; encourages a wider margin.

## 5. Kernel Trick

- Used when data cannot be separated using a linear decision boundary.
- Maps data implicitly into a higher-dimensional feature space.
- Allows SVM to learn nonlinear decision boundaries without explicitly computing the transformation.

### Common Kernels

1. **Linear Kernel:** `K(x,z) = xᵀz`
2. **Polynomial Kernel:** `K(x,z) = (xᵀz + c)ᵈ`
3. **RBF (Gaussian) Kernel:** `K(x,z) = exp(-γ ||x-z||²)`
4. **Sigmoid Kernel:** Similar in form to a neural network activation function.

Where:

- `γ` controls the influence of individual training points in the RBF kernel.
- `d` = Polynomial degree.
- `c` = Constant.

## 6. Hinge Loss

- SVM commonly uses hinge loss for classification.
- It penalizes incorrect classifications and points that lie inside the desired margin.

`L(y, f(x)) = max(0, 1 - y f(x))`

Where:

- `y` = Actual class label (-1 or +1).
- `f(x)` = Predicted decision score.

## 7. Advantages

- Effective in high-dimensional datasets.
- Works well when there is a clear margin of separation.
- Supports nonlinear classification using kernels.
- Decision boundary is determined by support vectors.

## 8. Disadvantages

- Computationally expensive for large datasets.    
- Choosing the right kernel and hyperparameters can be difficult.
- Sensitive to feature scaling.
- Less interpretable than simpler models.

## 9. SVM vs Logistic Regression

| Feature                  | SVM                    | Logistic Regression     |
| ------------------------ | ---------------------- | ----------------------- |
| Objective                | Maximize margin        | Maximize likelihood     |
| Decision boundary        | Hyperplane             | Hyperplane              |
| Output                   | Decision score / class | Probability             |
| Nonlinear classification | Kernel trick           | Feature transformations |
| Loss function            | Hinge loss             | Log loss                |

## 10. Key Takeaways

- SVM is a supervised learning algorithm.
- Finds an optimal hyperplane to separate classes.
- Maximizes the margin between classes.
- Closest data points are called support vectors.
- Kernel tricks enable nonlinear classification.
- C controls the trade-off between margin size and classification errors.    

**Remember:** SVM does not simply find a boundary that separates classes; it finds the boundary with the maximum possible margin.
