**Linear Models:**
- Machine learning models that learn a linear relationship between input features (X) and output (Y).
- General equation: y = wᵀx + b
- x: Input features
- w: Weights (learned parameters)
- b: Bias (intercept)
- y: Predicted output
- Examples: Linear Regression, Logistic Regression, Linear SVM.
- Used for regression and classification tasks.

# Machine Learning

## 1. Types of Machine Learning

- **Supervised Learning:** Model learns from labelled data (input + correct output).
- **Unsupervised Learning:** Model learns patterns or structures from unlabelled data.
- **Regression:** Predicts continuous numerical values.
- **Classification:** Predicts discrete categories or classes.
- **Clustering:** Groups similar data points without predefined labels.

## 2. Linear Regression

- Supervised learning algorithm used to predict continuous numerical values.
- Models the linear relationship between input features and output.
- **Equation:** `ŷ = wᵀx + b`
- `ŷ` = Predicted output, `w` = Weights, `x` = Input features, `b` = Bias.
- **Cost Function (MSE):** `MSE = (1/N) Σ (yᵢ - ŷᵢ)²`
- **Objective:** Minimize the difference between actual and predicted values.
- **Examples:** House price prediction, salary prediction.

## 3. Classification & Logistic Regression

### Classification

- Supervised learning task that predicts discrete categories or classes.
- **Binary Classification:** Two classes (0 or 1).
- **Multiclass Classification:** More than two classes.
- **Examples:** Spam detection, fraud detection.

### Logistic Regression

- Supervised learning algorithm used primarily for classification.
- Predicts the probability of an input belonging to a particular class.
- **Linear Combination:** `z = wᵀx + b`
- **Sigmoid Function:** `σ(z) = 1 / (1 + e⁻ᶻ)`
- Converts output into a probability between 0 and 1.
- **Decision Threshold:** Probability ≥ 0.5 → Class 1; Probability < 0.5 → Class 0.
- **Loss Function (Binary Cross-Entropy):** `L = -[y log(ŷ) + (1-y) log(1-ŷ)]`
- **Examples:** Spam detection, disease prediction.

## 4. Linear vs Logistic Regression

|Linear Regression|Logistic Regression|
|---|---|
|Predicts continuous values|Predicts class probabilities|
|Linear function|Sigmoid function|
|MSE loss|Cross-Entropy loss|
|House price prediction|Spam detection|

# Formal Regression Problem

>[!abstract] Overview
>The **formal regression problem** establishes the mathematical foundation for predicting continuous target values from multidimensional input features by minimizing empirical risk over a parameter space.

---

## 1. Mathematical Formulation

### Dataset Definition
Given a training dataset of $N$ instances:
* **Feature Vector ($\mathbf{x}_i$):** A $D$-dimensional input vector for instance $i$:
  $$\mathbf{x}_i \in \mathbb{R}^D \quad \forall i \in \{1, \dots, N\}$$
* **Target ($y_i$):** A uni-dimensional continuous scalar label:
  $$y_i \in \mathbb{R} \quad \forall i \in \{1, \dots, N\}$$

---

### Unconstrained Objective
The general goal of regression is to find a mapping function $\hat{y} := f : \mathbb{R}^D \mapsto \mathbb{R}$ that estimates $y$ by minimizing a non-negative **Loss Function** $J : \mathbb{R} \times \mathbb{R} \mapsto \mathbb{R}_+$:

$$\arg \min_{f} \sum_{i=1}^{N} J(y_i, f(\mathbf{x}_i))$$

---

### Refined Objective (Parametric Models)
Because searching over all possible arbitrary functions is computationally intractable, machine learning restricts the search space to a **parametric family** of functions $f(\mathbf{x}_i; \mathbf{w})$ parameterized by weights $\mathbf{w} \in W$:

$$\arg \min_{\mathbf{w} \in W} \sum_{i=1}^{N} J(y_i, f(\mathbf{x}_i; \mathbf{w}))$$

---

## 2. Practical Example: House Price Prediction

>[!example] Real-World Application
>Predicting historical house prices based on physical attributes.

### 1. Feature Representation
For $N = 3$ houses with $D = 2$ features ($\text{size in m}^2$, $\text{number of rooms}$):

* $\mathbf{x}_1 = \begin{bmatrix} 80 \\ 3 \end{bmatrix}$ with target $y_1 = 250$ (€250k)
* $\mathbf{x}_2 = \begin{bmatrix} 120 \\ 4 \end{bmatrix}$ with target $y_2 = 380$ (€380k)
* $\mathbf{x}_3 = \begin{bmatrix} 60 \\ 2 \end{bmatrix}$ with target $y_3 = 190$ (€190k)

### 2. Parametric Hypothesis (Linear Regression)
$$f(\mathbf{x}_i; \mathbf{w}) = w_0 + w_1 x_{i,1} + w_2 x_{i,2}$$

where $\mathbf{w} = [w_0, w_1, w_2]^T \in \mathbb{R}^3$ are the trainable parameters.

### 3. Loss Function (Squared Error)
$$J(y_i, f(\mathbf{x}_i; \mathbf{w})) = \left(y_i - f(\mathbf{x}_i; \mathbf{w})\right)^2$$

### 4. Optimization
$$\mathbf{w}^* = \arg \min_{\mathbf{w} \in \mathbb{R}^3} \sum_{i=1}^{3} \left( y_i - (w_0 + w_1 x_{i,1} + w_2 x_{i,2}) \right)^2$$

---


$$\arg \min_{\mathbf{w} \in W} \sum_{i=1}^{N} J(y_i, f(\mathbf{x}_i; \mathbf{w}))$$

### Problem Setup

Let’s define a dataset of $N = 3$ instances with $D = 2$ features:

- **Instance 1:** $\mathbf{x}_1 = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$, $y_1 = 5$
- **Instance 2:** $\mathbf{x}_2 = \begin{bmatrix} 2 \\ 1 \end{bmatrix}$, $y_2 = 4$
- **Instance 3:** $\mathbf{x}_3 = \begin{bmatrix} 0 \\ 3 \end{bmatrix}$, $y_3 = 6$

#### 1. Parametric Model ($f(\mathbf{x}_i; \mathbf{w})$)

We restrict our function space $W$ to a 2D linear model without bias:

$$f(\mathbf{x}_i; \mathbf{w}) = w_1 x_{i,1} + w_2 x_{i,2} = \mathbf{w}^T \mathbf{x}_i$$

where $\mathbf{w} = \begin{bmatrix} w_1 \\ w_2 \end{bmatrix} \in \mathbb{R}^2$.

#### 2. Loss Function ($J$)

We use the standard half-squared error loss:

$$J(y_i, f(\mathbf{x}_i; \mathbf{w})) = \frac{1}{2} \left( y_i - f(\mathbf{x}_i; \mathbf{w}) \right)^2$$

### Step-by-Step Optimization

#### Step 1: Write out the Objective Function

Expanding the refined objective $\sum_{i=1}^{3} J(y_i, f(\mathbf{x}_i; \mathbf{w}))$ gives:

$$L(\mathbf{w}) = \frac{1}{2} \left[ (5 - (w_1 + 2w_2))^2 + (4 - (2w_1 + w_2))^2 + (6 - (0\cdot w_1 + 3w_2))^2 \right]$$

#### Step 2: Set Gradient to Zero ($\nabla_{\mathbf{w}} L = \mathbf{0}$)

To find $\mathbf{w}^* = \arg \min_{\mathbf{w} \in W} L(\mathbf{w})$, take partial derivatives with respect to $w_1$ and $w_2$:

1. **Partial Derivative $\frac{\partial L}{\partial w_1}$:**
    
    $$\frac{\partial L}{\partial w_1} = -1(5 - w_1 - 2w_2) - 2(4 - 2w_1 - w_2) - 0(6 - 3w_2) = 0$$
    $$-5 + w_1 + 2w_2 - 8 + 4w_1 + 2w_2 = 0$$
    $$5w_1 + 4w_2 = 13 \quad \text{--- (Equation 1)}$$
    
1. **Partial Derivative $\frac{\partial L}{\partial w_2}$:**
    $$\frac{\partial L}{\partial w_2} = -2(5 - w_1 - 2w_2) - 1(4 - 2w_1 - w_2) - 3(6 - 3w_2) = 0$$
    $$-10 + 2w_1 + 4w_2 - 4 + 2w_1 + w_2 - 18 + 9w_2 = 0$$
    $$4w_1 + 14w_2 = 32 \quad \text{--- (Equation 2)}$$

#### Step 3: Solve the Linear System

From **(Equation 1)**: $w_1 = \frac{13 - 4w_2}{5}$

Substitute $w_1$ into **(Equation 2)**:

$$4\left(\frac{13 - 4w_2}{5}\right) + 14w_2 = 32$$

$$\frac{52 - 16w_2 + 70w_2}{5} = 32$$

$$52 + 54w_2 = 160 \implies 54w_2 = 108 \implies w_2^* = 2$$

Now solve for $w_1^*$:

$$w_1^* = \frac{13 - 4(2)}{5} = \frac{5}{5} = 1$$

### Solution

$$\mathbf{w}^* = \arg \min_{\mathbf{w} \in W} \sum_{i=1}^{3} J(y_i, f(\mathbf{x}_i; \mathbf{w})) = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$$

- **Final Parametric Model:** $f(\mathbf{x}_i; \mathbf{w}^*) = 1 \cdot x_{i,1} + 2 \cdot x_{i,2}$
    
- **Predictions Check:**
    - $f(\mathbf{x}_1) = 1(1) + 2(2) = 5$ (Exact match for $y_1 = 5$)
    - $f(\mathbf{x}_2) = 1(2) + 2(1) = 4$ (Exact match for $y_2 = 4$)
    - $f(\mathbf{x}_3) = 1(0) + 2(3) = 6$ (Exact match for $y_3 = 6$)
- **Minimum Total Loss:** $L(\mathbf{w}^*) = 0$
