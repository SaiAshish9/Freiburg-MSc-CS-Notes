# Machine Learning

## 1. Types of Machine Learning

- **Supervised Learning:** Model learns from labelled data (input + correct output).
- **Unsupervised Learning:** Model learns patterns or structures from unlabelled data.
- **Regression:** Predicts continuous numerical values.
- **Classification:** Predicts discrete categories or classes.
- **Clustering:** Groups similar data points without predefined labels.

## 2. Linear Regression

- Supervised learning algorithm used to predict continuous numerical values.
- Models the linear relationship between input features and output.
- **Equation:** `ŷ = wᵀx + b`
- `ŷ` = Predicted output, `w` = Weights, `x` = Input features, `b` = Bias.
- **Cost Function (MSE):** `MSE = (1/N) Σ (yᵢ - ŷᵢ)²`
- **Objective:** Minimize the difference between actual and predicted values.
- **Examples:** House price prediction, salary prediction.

## 3. Classification & Logistic Regression

### Classification

- Supervised learning task that predicts discrete categories or classes.
- **Binary Classification:** Two classes (0 or 1).
- **Multiclass Classification:** More than two classes.
- **Examples:** Spam detection, fraud detection.

### Logistic Regression

- Supervised learning algorithm used primarily for classification.
- Predicts the probability of an input belonging to a particular class.
- **Linear Combination:** `z = wᵀx + b`
- **Sigmoid Function:** `σ(z) = 1 / (1 + e⁻ᶻ)`
- Converts output into a probability between 0 and 1.
- **Decision Threshold:** Probability ≥ 0.5 → Class 1; Probability < 0.5 → Class 0.
- **Loss Function (Binary Cross-Entropy):** `L = -[y log(ŷ) + (1-y) log(1-ŷ)]`
- **Examples:** Spam detection, disease prediction.

## 4. Linear vs Logistic Regression

|Linear Regression|Logistic Regression|
|---|---|
|Predicts continuous values|Predicts class probabilities|
|Linear function|Sigmoid function|
|MSE loss|Cross-Entropy loss|
|House price prediction|Spam detection|
