# Tumor Classification with Linear Regression: The Green Lines

The **green lines** represent different **linear regression hypothesis models** ($h_w(x) = w^T x$) fitted to the dataset. 

## Why Are There Two Lines?
* **Lighter Green Line**: The fitted model for the initial cluster of data points.
* **Darker Green Line**: The updated model after a new data point (the isolated red cross on the far right) is introduced.

## The Core Lesson Illustrated
This comparison demonstrates why linear regression fails for classification tasks: **extreme sensitivity to outliers**.
* Adding a single point far out on the $x$-axis drastically changes the slope and position of the best-fit line.
* Because the line shifts, the decision threshold ($0.5$) moves, which can cause points to be misclassified even when the classes are cleanly separated. This flaw motivates the switch to **logistic regression**, which bounds outputs between $0$ and $1$.

# Tumor Classification: Linear Approach & Oracle Solution

> [!NOTE] Overview
> Binary classification task determining whether a tumor is benign or malignant based on an input feature (e.g., tumor size $x$).

## 1. Problem Formulation
* **Target Labels**: $y \in \{0, 1\}$
  * $y = 0$: **Negative class** (e.g., benign, not malignant)
  * $y = 1$: **Positive class** (e.g., malignant)

## 2. Linear Regression Baseline
* Try fitting an augmented linear model:
  $$h_w(x) = w^T x$$
  using standard linear regression techniques.

> [!WARNING] Limitation of Linear Fit
> Linear regression outputs continuous values over $(-\infty, +\infty)$, which can drift past $[0, 1]$ and be heavily skewed by outliers when applied directly to binary labels.

## 3. Oracle Decision Rule
To map continuous predictions to discrete class boundaries, an oracle decision rule uses a threshold of $0.5$:
* If $h_w(x) > 0.5$, predict $y = 1$ (**malignant**).
* If $h_w(x) \leq 0.5$, predict $y = 0$ (**not malignant**).
