# Convex Loss Functions & Logistic Regression Loss

> [!NOTE] Overview
> These slides cover why **convexity** is crucial for optimization in machine learning, and how the **Binary Cross-Entropy (Log Loss)** function is constructed for logistic regression to guarantee a convex optimization landscape.

---

## Part 1: Convex vs. Non-Convex Loss Functions

### 1. Why Convexity Matters
* **Dependency**: The loss for any data point $(x, y)$ depends directly on the model parameters $w$: $J(h_w, y)$.
* **Easier Optimization**: Parameters $w_i$ can be optimized much more reliably and efficiently if the loss function is **convex** and **(continuously) differentiable**.

### 2. Geometric Comparison
* **Convex Loss (Left)**: 
  * Shaped like a bowl. 
  * Any chord (line segment) drawn between two points on the curve stays above or on the curve.
  * Features a single **global minimum** with no deceptive local minima. Optimization algorithms like gradient descent are guaranteed to find the optimal global solution regardless of where they start.
* **Non-Convex Loss (Right)**: 
  * Wavy shape with multiple peaks and valleys.
  * Contains **local minimum** points where optimization algorithms can get permanently stuck, failing to reach the lowest possible global error.

---

## Part 2: Loss Function of Logistic Regression

If we tried to use Mean Squared Error (MSE) with logistic regression's non-linear sigmoid activation, the resulting cost function would be **non-convex** (full of wavy local minima). To solve this, we use **Binary Cross-Entropy (Log Loss)**.

### 1. Piecewise Formulation
The loss function penalizes wrong predictions heavily by taking the negative logarithm of the predicted probability for the correct class:

$$J(h_w(y_i, x_i)) = \begin{cases} 
-\log(1 - h_w(x_i)) & \text{for } y_i = 0 \\ 
-\log(h_w(x_i)) & \text{for } y_i = 1 
\end{cases}$$

* **When $y_i = 1$**: If the model predicts close to $1$, cost $\to 0$. If the model confidently predicts close to $0$, cost $\to \infty$ (massive penalty).
* **When $y_i = 0$**: If the model predicts close to $0$ (so $1 - h_w(x) \to 1$), cost $\to 0$. If it predicts close to $1$, cost $\to \infty$.

### 2. Compact Formulation
To avoid case-by-case evaluation, the two conditions can be merged into a single equation:

$$J(h_w(x_i), y_i) = - \left( (1 - y_i)\log(1 - h_w(x_i)) + y_i \log(h_w(x_i)) \right)$$

### 3. Key Properties
* **Nice Property**: $J$ is strictly **convex**, creating a smooth bowl-like error surface that prevents gradient descent from getting trapped in local minima.
* **Not-So-Nice Property**: There is **no analytic (closed-form) solution** (unlike ordinary least squares linear regression which has the normal equation). Instead, we rely on iterative optimization algorithms like **gradient descent** to find the minimum.

# Ordinary Least Squares (OLS) Linear Regression

> [!NOTE] Objective
> Find the optimal parameters $w$ that minimize the **Sum of Squared Errors (SSE)** between predicted values $\hat{y}$ and actual target values $y$:
> $$\min_w \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

---

## 1. Matrix Form (General Normal Equation)
For a dataset with feature matrix $X$ and target vector $y$, the closed-form analytical solution for the weight vector $w$ is:

$$w = (X^T X)^{-1} X^T y$$

* **$X$**: Design matrix of input features ($n \times (d+1)$, including a leading column of $1$s for the bias/intercept term $w_0$).
* **$y$**: Vector of actual target values ($n \times 1$).
* **$w$**: Vector of learned weights ($(d+1) \times 1$).

> [!WARNING] Computational Note
> Computing $(X^T X)^{-1}$ has a time complexity of $\mathcal{O}(d^3)$ and requires $X^T X$ to be invertible (full rank). For very large feature counts ($d$), iterative methods like **Gradient Descent** are preferred.

---

## 2. Univariate Form (Simple Linear Regression)
For a single input feature $x$ predicting $y$ via the linear model $\hat{y} = w_0 + w_1 x$:

* **Slope ($w_1$)**:
  $$w_1 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2} = \frac{\text{Cov}(x, y)}{\text{Var}(x)}$$

* **Intercept ($w_0$)**:
  $$w_0 = \bar{y} - w_1 \bar{x}$$

*(Where $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$ and $\bar{y} = \frac{1}{n}\sum_{i=1}^n y_i$ are the sample means).*

# Iterative Optimization

> [!NOTE] Definition
> **Iterative optimization** is a mathematical and computational process used to find the optimal solution (such as minimizing a loss function) by starting with an initial guess and repeatedly refining it through a sequence of sequential steps until a stopping condition is reached.

---

## 1. Iterative vs. Analytical (Closed-Form) Solutions

To understand iterative optimization, it helps to contrast it with direct mathematical solutions:

* **Analytical / Closed-Form Solution**: 
  * Solves a problem directly using a formula in a single step.
  * *Example*: Ordinary Least Squares linear regression uses the normal equation $w = (X^T X)^{-1} X^T y$ to calculate the optimal weights instantly.
* **Iterative Optimization**: 
  * Approximates the solution step-by-step because a direct formula does not exist (or is too computationally expensive to compute).
  * *Example*: Logistic regression loss functions have no closed-form analytical solution, requiring iterative methods like gradient descent to find the minimum.

---

## 2. The Step-by-Step Iterative Loop

Every iterative optimization algorithm follows a continuous loop until it achieves **convergence** (the point where further iterations stop producing meaningful improvements):

1. **Initialization**: Start with an initial estimate for the parameters (e.g., random weights $w$).
2. **Evaluation**: Measure how good or bad the current parameters are by calculating the cost/loss function $J(w)$.
3. **Compute the Gradient**: Determine the direction and rate of steepest change (the slope or derivative).
4. **Update Parameters**: Adjust the parameters slightly in the direction that reduces the error (e.g., moving down the slope using gradient descent):
   $$w^{\text{(next)}} \leftarrow w^{\text{(prev)}} - \eta \frac{\partial J(w)}{\partial w^{\text{(prev)}}}$$
5. **Check Stopping Criteria**: Repeat steps 2–4 until the changes in cost become negligible or a maximum number of steps is reached.

---

## 3. Key Trade-offs

| Feature | Iterative Optimization (e.g., Gradient Descent) | Closed-Form Solution (e.g., Normal Equation) |
| :--- | :--- | :--- |
| **Applicability** | Works for both convex and complex loss functions (including deep learning and logistic regression). | Limited to models with differentiable, solvable linear equations. |
| **Scalability** | Handles massive datasets and high-dimensional feature spaces very efficiently ($\mathcal{O}(d)$ per iteration). | Becomes computationally prohibitive or impossible when feature matrices are huge ($O(d^3)$ complexity for matrix inversion). |
| **Exactness** | Approximates the minimum (gets extremely close depending on the learning rate and steps). | Yields the exact mathematical minimum directly. |
