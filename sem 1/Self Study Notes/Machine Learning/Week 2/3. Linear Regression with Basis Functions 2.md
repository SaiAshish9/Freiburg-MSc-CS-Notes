# Alternative Loss Functions: L1 vs L2

>[!abstract] Key Takeaway
>The choice of loss function determines how a model reacts to error magnitude. **$L_2$ Loss** penalizes larger residual errors quadratically, making it sensitive to outliers. **$L_1$ Loss** penalizes errors linearly, making the model more robust to noisy data and extreme points.

---

## 1. Mathematical Definitions

Let $y$ be the ground-truth target and $\hat{y}$ be the model's prediction. The residual error is defined as $(y - \hat{y})$.

### L2 Loss (Squared Error)
$$J(y, \hat{y}) = (y - \hat{y})^2$$

* **Geometric Curve:** Smooth, convex parabola (quadratically increasing penalty).
* **Derivatives:** Continuously differentiable everywhere, making it well-suited for standard gradient descent algorithms.

### L1 Loss (Absolute Error)
$$J(y, \hat{y}) = |y - \hat{y}|$$

* **Geometric Curve:** V-shaped linear plot (linearly increasing penalty).
* **Derivatives:** Non-differentiable at $y - \hat{y} = 0$, requiring subgradient methods or specialized solvers.

---

## 2. Comparison & Properties

| Feature | $L_2$ Loss (Squared Error) | $L_1$ Loss (Absolute Error) |
| :--- | :--- | :--- |
| **Formula** | $(y - \hat{y})^2$ | $\|y - \hat{y}\|$ |
| **Sensitivity to Outliers** | High (heavily penalizes large errors) | Low (robust to outliers) |
| **Error Penalty Growth** | Quadratic | Linear |
| **Optimal Central Tendency** | Estimates the **Mean** | Estimates the **Median** |
| **Computational Efficiency** | Smooth gradient, easier to optimize | Non-differentiable at zero |

---

## 3. Impact on Model Fitting

>[!warning] Outlier Sensitivity
>* **With $L_2$:** Outliers are heavily penalized ($error^2$). To minimize the total accumulated loss, the fitting line is forced to pull itself heavily toward extreme data points, often compromising performance on typical data.
>* **With $L_1$:** Outliers do not exert a disproportionate pull because the penalty increases linearly with error magnitude rather than exponentially.

In statistics and machine learning, an **outlier** is a data point that deviates significantly from the overall pattern, trend, or distribution of the rest of the dataset.

In the context of regression analysis (as shown in your lecture slide), outliers are data points that lie unusually far away from the fitted model's prediction line. On a scatter plot, you can easily spot them because they have much larger vertical residual errors (represented by the long red lines in the slide's graph) compared to the rest of the data points.

>[!question] Discussion Question
>**In which situations would you expect absolute loss ($L_1$) to be preferable compared to squared loss ($L_2$)?**

1. **Robustness to Outliers & Noise:** When the dataset contains erroneous measurements or heavy-tailed noise. $L_1$ grows linearly rather than quadratically, preventing outliers from dominating the gradient.
2. **Skewed Target Distributions:** When estimating the central tendency of a skewed distribution, $L_1$ estimates the **median**, whereas $L_2$ estimates the **mean** (which is easily pulled by extreme values).
3. **Linear Cost Requirements:** When real-world domain costs scale proportionally with error magnitude rather than quadratically (e.g., SLA penalties, time delays).
