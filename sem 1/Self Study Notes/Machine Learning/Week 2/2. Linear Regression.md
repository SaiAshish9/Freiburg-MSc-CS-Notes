# Linear Regression with Basis Functions

> [!abstract] Core idea
> Transform the inputs with fixed **nonlinear functions**, then run ordinary **linear regression** on the transformed features.

## Model

$$f(\mathbf{x}, \mathbf{w}) = w_0 + \sum_{j=1}^{M} w_j \, \phi_j(\mathbf{x})$$

- $\phi : \mathbb{R}^D \to \mathbb{R}^M$ maps $D$ original features to $M$ new features
- $\phi_j(\mathbf{x})$ are the **basis functions**, fixed and chosen in advance (e.g. $x^2$, $\sin x$, Gaussian bumps)
- $w_j$ are the weights learned from data

## Why it's still "linear"

> [!important] Two key characteristics
> 1. $f$ is **linear in the weights** $\mathbf{w}$
> 2. $f$ is **nonlinear in the inputs** $\mathbf{x}$

- Training only needs linearity in $\mathbf{w}$, so the usual least-squares machinery still works
- Because $\phi$ is nonlinear, the fitted curve in $x$ can bend

Closed-form solution:

$$\mathbf{w} = (\Phi^\top \Phi)^{-1} \Phi^\top \mathbf{y}$$

where $\Phi$ has rows $[1, \phi_1(x_i), \dots, \phi_M(x_i)]$.

## Example 1: Polynomial basis

Data with a U-shape, e.g. house price vs. age ($D = 1$). A straight line fails, so choose:

- $\phi_1(x) = x$
- $\phi_2(x) = x^2$

$$f(x, \mathbf{w}) = w_0 + w_1 x + w_2 x^2$$

Here $D = 1$, $M = 2$: each $x$ becomes the feature vector $(x, x^2)$.

With $w_0 = 2,\ w_1 = -3,\ w_2 = 1$:

| $x$ | $\phi_1 = x$ | $\phi_2 = x^2$ | $f = 2 - 3x + x^2$ |
|---|---|---|---|
| 0 | 0 | 0 | 2 |
| 1 | 1 | 1 | 0 |
| 2 | 2 | 4 | 0 |
| 3 | 3 | 9 | 2 |

> [!note]
> The output is a parabola (nonlinear in $x$), but $\mathbf{w}$ was found with plain linear least squares on the columns $[1, x, x^2]$.

## Takeaway

Basis functions let you model curved relationships while keeping the simple, convex, closed-form world of linear regression.

> [!warning] Catch
> You must choose the basis functions yourself (type, number $M$, centers, widths).
> - Too few → **underfit**
> - Too many → **overfit**
