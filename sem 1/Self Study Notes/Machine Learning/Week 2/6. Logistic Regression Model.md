# The Sigmoid Function in Logistic Regression

The **sigmoid function** (also known as the logistic function) is the core mathematical transformation used in logistic regression to solve the limitations of standard linear regression.

## 1. Mathematical Definition
The sigmoid function $\sigma(z)$ is defined as:
$$\sigma(z) = \frac{1}{1 + e^{-z}}$$
where $z = w^T x$ represents the linear output (the combination of weights and features).

---

## 2. What It Does
* **Bounds Outputs to Probabilities**: It takes any real-valued number from $(-\infty, +\infty)$ and "squeezes" or maps it strictly into a range between **0 and 1** $(0 < \sigma(z) < 1)$. 
* **Prevents Invalid Predictions**: Unlike linear regression—which can generate values greater than $1$ or less than $0$—the sigmoid function ensures the output stays within valid bounds: $0 \le h_w(x) \le 1$.
* **Provides a Smooth Threshold**: It forms an S-shaped curve that converts continuous scores into interpretable probabilities (e.g., a 0.85 output means an 85% probability that the tumor is malignant).
* **Enables Gradient Descent**: Because the sigmoid function is continuous and differentiable everywhere, optimization algorithms like gradient descent can easily compute gradients to update the model weights.

---

# Sigmoid Function: Activation vs. Loss Function

> [!NOTE] Quick Distinction
> The sigmoid function is an **activation (hypothesis) function**, *not* a loss function. They serve completely different roles during model training.

---

## 1. The Sigmoid Function (Activation / Hypothesis)
* **Mathematical Definition**: 
  $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
  where $z = w^T x$ is the linear model output.
* **Role**: It acts as the activation function applied to the linear combination of inputs and weights ($h_w(x) = \sigma(w^T x)$). 
* **Key Function**: It takes any real-valued number from $(-\infty, +\infty)$ and squashes it strictly into a probability range between **0 and 1** ($0 < \sigma(z) < 1$).

---

## 2. The Loss Function (Binary Cross-Entropy / Log Loss)
* **Role**: A separate mathematical function used during optimization to measure *how wrong* the model's predictions are compared to the ground truth labels ($y \in \{0, 1\}$).
* **How They Work Together**:
  1. **Sigmoid** calculates the prediction $\hat{y} = \sigma(w^T x)$ (e.g., $0.85$ probability).
  2. **Loss Function** (such as Binary Cross-Entropy) evaluates that prediction against the true label ($y = 1$) to compute the penalty or error.
  3. **Gradient Descent** uses that error to update the weights ($w$).

---
# Activation Functions in Neural Networks

> [!NOTE] Definition
> An **activation function** is a mathematical operation applied to the output of a neuron (the weighted sum of inputs plus a bias) before passing it on to the next layer. 

---

## 1. Why Do We Need Activation Functions?
* **Introduce Non-Linearity**: Without activation functions, a neural network—regardless of how many hidden layers it has—would behave just like a single linear regression model. Stacking linear layers together only results in another linear function. Activation functions allow networks to learn complex, non-linear patterns (e.g., curves, boundaries, images, language).
* **Control Output Range**: They map the unbounded output of linear combinations ($z = w^T x + b$) into specific, bounded ranges (like $[0, 1]$ for probabilities).

---

## 2. Common Types of Activation Functions

### A. Sigmoid (Logistic)
* **Formula**: $\sigma(z) = \frac{1}{1 + e^{-z}}$
* **Range**: $(0, 1)$
* **Use Case**: Output layer for binary classification tasks.
* **Drawback**: Prone to the *vanishing gradient problem* for very high or low inputs, where the gradient becomes nearly zero, halting learning.

### B. ReLU (Rectified Linear Unit)
* **Formula**: $\text{ReLU}(x) = \max(0, x)$
* **Range**: $[0, \infty)$
* **Use Case**: Hidden layers in most modern deep neural networks.
* **Advantages**: Computationally efficient and mitigates the vanishing gradient problem for positive inputs.
* **Drawback**: *Dying ReLU problem*—if a neuron gets stuck with a negative input, its gradient becomes 0, and it stops updating permanently.

### C. Leaky ReLU
* **Formula**: $\text{Leaky ReLU}(x) = \max(\alpha x, x)$ (where $\alpha$ is a small constant like $0.01$)
* **Range**: $(-\infty, \infty)$
* **Advantage**: Solves the "dying ReLU" problem by allowing a small, non-zero gradient when the input is negative.

### D. Tanh (Hyperbolic Tangent)
* **Formula**: $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$
* **Range**: $(-1, 1)$
* **Advantage**: Zero-centered (unlike sigmoid), making optimization easier for subsequent layers. Still suffers from vanishing gradients.

### E. Softmax
* **Formula**: $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$
* **Range**: $(0, 1)$, with all outputs summing to $1$.
* **Use Case**: Output layer for **multi-class classification** problems to represent a probability distribution across multiple mutually exclusive classes.

# Example in $\mathbb{R}^2$: Decision Boundary in Logistic Regression

> [!NOTE] Overview
> This slide demonstrates how a logistic regression model defines a **decision boundary** in a 2-dimensional feature space ($\mathbb{R}^2$) using two input features, $x_1$ and $x_2$.

---

## 1. Model Setup
* **Data Visualization**: The feature space contains two distinct classes separated spatially—blue circles ($y = 0$) clustered near the origin and red crosses ($y = 1$) located further up and right.
* **Hypothesis Function**: 
  $$h_w(x) = g(w_0 + w_1 x_1 + w_2 x_2)$$
  where $g(\cdot)$ is the sigmoid activation function.

---

## 2. Weights and Decision Rule
* **Weight Vector ($w$)**: 
  $$w = \begin{bmatrix} -3 \\ 1 \\ 1 \end{bmatrix}$$
  This gives a bias term $w_0 = -3$, along with feature weights $w_1 = 1$ and $w_2 = 1$.
* **Prediction Condition**: The model predicts "$y = 1$" when the weighted sum is greater than or equal to zero:
  $$-3 + x_1 + x_2 \ge 0$$

---

## 3. Deriving the Decision Boundary
* The decision boundary represents the exact threshold where the model yields a probability of $0.5$ ($h_w(x) = 0.5$), meaning the linear input equals zero:
  $$x_1 + x_2 = 3 \iff h_w(x) = 0.5$$
* Geometrically, this equation defines a straight line on the 2D plane that acts as the dividing line between the two classes.

---

## 4. Key Takeaway & Remark
> [!TIP] Non-Linear Boundaries
> As in standard linear models, incorporating **additional dimensions and basis functions** (such as polynomial terms like $x_1^2$, $x_2^2$, or interaction terms like $x_1 x_2$) allows the model to create flexible, **non-linear decision boundaries** capable of separating complex data distributions.
