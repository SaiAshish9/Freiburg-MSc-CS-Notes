## Regularized Hinge Loss & Nonlinear Kernel SVMs

### 1. Regularized Hinge Loss Optimization (Primal Soft-Margin SVM)
In the constrained soft-margin SVM formulation:
$$\begin{aligned}
\min_{\boldsymbol{w}, w_0, \boldsymbol{\xi}} \quad & \frac{1}{2}\|\boldsymbol{w}\|_2^2 + C \sum_{i=1}^N \xi_i \\
\text{s.t.} \quad & \forall i:\; y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0) \ge 1 - \xi_i, \quad \xi_i \ge 0
\end{aligned}$$

* **Slack Variable Elimination:** Since $\xi_i \ge 1 - y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0)$ and $\xi_i \ge 0$, minimizing $\sum_{i=1}^N \xi_i$ forces each slack variable to its tightest lower bound:
  $$\xi_i^* = \max\Big(0,\; 1 - y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0)\Big)$$
* **Hinge Loss Definition:** For $f(\boldsymbol{x}_i) = \boldsymbol{w}^\top \boldsymbol{x}_i + w_0$, the hinge loss is:
  $$\ell_{\text{hinge}}\big(y_i, f(\boldsymbol{x}_i)\big) = \max\big(0,\; 1 - y_i f(\boldsymbol{x}_i)\big)$$
* **Unconstrained Optimization Forms:**
  $$\min_{\boldsymbol{w}, w_0} \; \frac{1}{2}\|\boldsymbol{w}\|_2^2 + C \sum_{i=1}^N \max\Big(0,\; 1 - y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0)\Big)$$
  $$\min_{\boldsymbol{w}, w_0} \; \frac{1}{N} \sum_{i=1}^N \max\Big(0,\; 1 - y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0)\Big) + \frac{\lambda}{2}\|\boldsymbol{w}\|_2^2$$
* **Key Properties:**
  * **Margin Penalty:** $\ell_{\text{hinge}} = 0$ when $y_i f(\boldsymbol{x}_i) \ge 1$. Points correctly classified inside the margin ($0 < y_i f(\boldsymbol{x}_i) < 1$) still incur a positive loss.
  * **Convexity:** The objective is convex and unconstrained, allowing optimization via subgradient descent or SGD despite the non-differentiable kink at $y_i f(\boldsymbol{x}_i) = 1$.

### 2. Nonlinear Kernel SVMs
In the dual formulation, replacing inner products with a kernel function $K(\boldsymbol{p}, \boldsymbol{q}) = \phi(\boldsymbol{p})^\top \phi(\boldsymbol{q})$ yields a nonlinear decision function in input space:
$$f(\boldsymbol{x}; \boldsymbol{\alpha}, w_0) = \operatorname{sign}\!\left(\sum_{i=1}^N \alpha_i y_i K(\boldsymbol{x}_i, \boldsymbol{x}) + w_0\right)$$

* **Common Kernels:**
  * **RBF (Gaussian) Kernel:** $K(\boldsymbol{p}, \boldsymbol{q}) = e^{-\gamma \|\boldsymbol{p} - \boldsymbol{q}\|_2^2}$
  * **Polynomial Kernel:** $K(\boldsymbol{p}, \boldsymbol{q}) = (\boldsymbol{p}^\top \boldsymbol{q} + c)^d$

#### Worked Example: 2D Polynomial Kernel ($c = 0, d = 2$)
Let $\boldsymbol{x} = (x_1, x_2)^\top \in \mathbb{R}^2$ with kernel $K(\boldsymbol{p}, \boldsymbol{q}) = (\boldsymbol{p}^\top \boldsymbol{q})^2$ (corresponding to $\phi(\boldsymbol{x}) = (x_1^2, \sqrt{2}x_1x_2, x_2^2)^\top$).

1. **Support Vectors & Parameters:**
   * $\boldsymbol{x}_1 = (1, 0)^\top,\; y_1 = +1,\; \alpha_1 = 1$
   * $\boldsymbol{x}_2 = (0, 1)^\top,\; y_2 = +1,\; \alpha_2 = 1$
   * Bias: $w_0 = -1$
1. **Kernel Evaluations:**
   * $K(\boldsymbol{x}_1, \boldsymbol{x}) = (1 \cdot x_1 + 0 \cdot x_2)^2 = x_1^2$
   * $K(\boldsymbol{x}_2, \boldsymbol{x}) = (0 \cdot x_1 + 1 \cdot x_2)^2 = x_2^2$
1. **Decision Function & Boundary:**
   $$f(\boldsymbol{x}) = \operatorname{sign}\!\big((1)(+1)x_1^2 + (1)(+1)x_2^2 - 1\big) = \operatorname{sign}\!\left(x_1^2 + x_2^2 - 1\right)$$
   * The decision boundary $x_1^2 + x_2^2 = 1$ is a **unit circle** in $\mathbb{R}^2$ (nonlinear in $\boldsymbol{x}$), while remaining linear in the dual parameters $\boldsymbol{\alpha}, w_0$.

### Worked Numerical Example: Nonlinear Kernel SVM (Polynomial Degree 2)

Consider the dual kernel SVM decision function:
$$f(\boldsymbol{x}; \boldsymbol{\alpha}, w_0) = \operatorname{sign}\!\left(\sum_{i=1}^N \alpha_i y_i K(\boldsymbol{x}_i, \boldsymbol{x}) + w_0\right)$$

Let $\boldsymbol{x} = (x_1, x_2)^\top \in \mathbb{R}^2$ and use the **polynomial kernel** with $c = 0, d = 2$:
$$K(\boldsymbol{p}, \boldsymbol{q}) = (\boldsymbol{p}^\top \boldsymbol{q})^2$$
*(Implicitly matching the feature map $\phi(\boldsymbol{x}) = (x_1^2,\; \sqrt{2}x_1x_2,\; x_2^2)^\top$.)*

#### 1. Given Support Vectors & Parameters
* Support vector 1: $\boldsymbol{x}_1 = (1, 0)^\top$, $y_1 = +1$, $\alpha_1 = 1$
* Support vector 2: $\boldsymbol{x}_2 = (0, 1)^\top$, $y_2 = +1$, $\alpha_2 = 1$
* Bias / intercept: $w_0 = -1$

#### 2. Evaluate Kernels for Arbitrary $\boldsymbol{x} = (x_1, x_2)^\top$
* $K(\boldsymbol{x}_1, \boldsymbol{x}) = \big((1, 0)\begin{pmatrix}x_1 \\ x_2\end{pmatrix}\big)^2 = x_1^2$
* $K(\boldsymbol{x}_2, \boldsymbol{x}) = \big((0, 1)\begin{pmatrix}x_1 \\ x_2\end{pmatrix}\big)^2 = x_2^2$

#### 3. Decision Function & Boundary
$$f(\boldsymbol{x}) = \operatorname{sign}\!\big((1)(+1)(x_1^2) + (1)(+1)(x_2^2) - 1\big) = \operatorname{sign}\!\left(x_1^2 + x_2^2 - 1\right)$$

* **Decision Boundary:** $x_1^2 + x_2^2 = 1$ — a **unit circle** in $\mathbb{R}^2$ (curved/nonlinear in $\boldsymbol{x}$, while linear in the dual parameters $\boldsymbol{\alpha}, w_0$).
* **Test Point A — Origin $\boldsymbol{x} = (0, 0)^\top$:**
  $$f(0, 0) = \operatorname{sign}(0^2 + 0^2 - 1) = \operatorname{sign}(-1) = -1$$
* **Test Point B — Outside Circle $\boldsymbol{x} = (1, 1)^\top$:**
  $$f(1, 1) = \operatorname{sign}(1^2 + 1^2 - 1) = \operatorname{sign}(+1) = +1$$
