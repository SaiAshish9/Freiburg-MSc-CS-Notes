## Linear Model for Linearly-Separable Binary Classification

### Setup & Notation
- **Dataset:** $\mathcal{D} = \{(\boldsymbol{x}_i, y_i)\}_{i=1}^N$
- **Feature vector:** $\boldsymbol{x}_i \in \mathbb{R}^M$ ($M$ features per sample; $M = 2$ in the plot with axes $x_{:,1}$ and $x_{:,2}$)
- **Binary labels:** $y_i \in \{-1, 1\}$ (convenient for sign and margin formulations)
- **Data matrix:** $X \in \mathbb{R}^{N \times M}$, where the $i$-th row is $\boldsymbol{x}_i^\top$

### Hyperplane & Decision Rule
- **Hyperplane equation:** $\boldsymbol{w}^\top \boldsymbol{x} + w_0 = 0$ (dashed line in 2D)
  - $\boldsymbol{w} \in \mathbb{R}^M$: weight / normal vector perpendicular to the boundary, pointing toward $y = 1$ (red circles)
  - $w_0 \in \mathbb{R}$: bias / offset term shifting the boundary from the origin
- **Prediction rule:**
  - $\hat{y} = +1$ if $\boldsymbol{w}^\top \boldsymbol{x} + w_0 > 0$
  - $\hat{y} = -1$ if $\boldsymbol{w}^\top \boldsymbol{x} + w_0 < 0$
  - **Linear separability condition:** $\exists (\boldsymbol{w}, w_0)$ such that $y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0) > 0$ for all $i = 1, \dots, N$

### Key Takeaways
- Zero training error is achievable with a single linear boundary.
- When separable, infinitely many valid hyperplanes exist—motivating criteria like **maximum margin** (SVM) or iterative learning (Perceptron).
