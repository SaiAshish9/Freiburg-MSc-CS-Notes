**Regularized hinge loss optimization** is the unconstrained equivalent of the **soft-margin Support Vector Machine (SVM)** primal problem. Instead of introducing explicit slack variables $\xi_i$ with inequality constraints, it folds the margin violation penalty directly into the objective function using the **hinge loss**.
