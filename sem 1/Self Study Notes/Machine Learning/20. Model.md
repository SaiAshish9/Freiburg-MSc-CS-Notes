
### KNN Model

**Dataset:**
$$
\mathcal{D} = \{(x_1,y_1),(x_2,y_2),\ldots,(x_N,y_N)\}
$$

**Set of K Nearest Neighbors:**
$$
\mathcal{S}(x) := \arg\min_{\substack{\mathcal{S}\subset\mathcal{D}\\|\mathcal{S}|=k}}
\sum_{(x',y')\in\mathcal{S}}d(x',x)
$$

**Prediction Model:**
$$
f(x) := \operatorname{aggregate}(\pi_y(\mathcal{S}(x)))
$$

**Where:**
- $\mathcal{D}$ = Training dataset
- $x$ = New input point
- $k$ = Number of nearest neighbors
- $\mathcal{S}(x)$ = Set of K closest training samples
- $d(x',x)$ = Distance between two points
- $\pi_y$ = Extracts target values from neighbors
- $\operatorname{aggregate}$ = Combines targets to predict output

**Key Idea:** KNN selects the K closest training samples
and aggregates their target values to make a prediction.


Model: A mathematical function or algorithm used to predict outputs from input data.

KNN Model: Predicts outputs by aggregating the target values of the \(k\) nearest training samples.
