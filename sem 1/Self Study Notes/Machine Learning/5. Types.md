## Classification, Regression, and Ranking in Machine Learning

### 1. Classification
- Definition: Predicts a category or class from given input data.
- Output: Discrete labels (e.g., Yes/No, Spam/Not Spam).
- Example: Predicting whether an email is spam or not.
- Algorithms: Logistic Regression, SVM, Decision Trees, Neural Networks.

### 2. Regression
- Definition: Predicts a continuous numerical value based on input features.
- Output: Numbers (e.g., price, temperature, salary).
- Example: Predicting a house price based on its size and location.
- Algorithms: Linear Regression, Random Forest,  Decision Trees,  Neural Networks.

### 3. Ranking

- Definition: Arranges items in order based on relevance, preference, or importance.
- Output: An ordered list of items.
- Example: Google ranking search results based on relevance to a query.    
- Algorithms: RankNet, LambdaMART, Learning-to-Rank models.
    

## Key Differences

| Type           | Goal               | Example output                 |
| -------------- | ------------------ | ------------------------------ |
| Classification | Predict a category | Spam / Not Spam                |
| Regression     | Predict a number   | House price: €250,000          |
| Ranking        | Predict an order   | Result A → Result C → Result B |

Easy way to remember:

- Classification: Which category?
- Regression: How much or how many?
- Ranking: Which comes first?
