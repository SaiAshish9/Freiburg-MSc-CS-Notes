
A loss function measures the difference between the actual value (y) and the predicted value ( ̂𝑦). The goal of machine learning is to minimize the loss

**Explanation:** Regression uses real-valued targets; classification uses class labels. Squared loss penalizes large errors more strongly than L1. Logistic loss is for binary probability predictions; hinge loss is a margin-based classification loss.

$$\mathcal L_{L2}(y_n,\hat y_n)=(y_n-\hat y_n)^2$$

$$\mathcal L_{L1}(y_n,\hat y_n)=|y_n-\hat y_n|$$

$$\mathcal L_{log}(y_n,\hat y_n)=-y_n\log\hat y_n-(1-y_n)\log(1-\hat y_n)$$

$$\mathcal L_{hinge}(y_n,\hat y_n)=\max(0,1-y_n\hat y_n)$$

**Lecture slide content (reference):**

Regression (target is real-valued 𝑦𝑛∈ℝ)

- • Least-squares (Squared L2 Loss):
- 
- ℒ(𝑦𝑛, ̂𝑦𝑛) ≔(𝑦𝑛−̂𝑦𝑛)2

- • L1:
- ℒ(𝑦𝑛, ̂𝑦𝑛) ≔|𝑦𝑛−̂𝑦𝑛|

Binary Classification
- • Logistic loss, 𝑦𝑛∈{0, 1}:
- ℒ(𝑦𝑛, ̂𝑦𝑛) ≔−𝑦𝑛log(̂𝑦𝑛) −(1 −𝑦𝑛) log(1 −̂𝑦𝑛)

- • Hinge loss, 𝑦𝑛∈{−1, 1}:
- ℒ(𝑦𝑛, ̂𝑦𝑛) ≔max(0, 1 −𝑦𝑛̂𝑦𝑛)
