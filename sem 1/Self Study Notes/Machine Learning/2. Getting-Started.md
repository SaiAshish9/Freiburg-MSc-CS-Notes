
# Machine Learning (ML) – Types and Course Topics

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.


**Types of Machine Learning**

1. Supervised Learning

Learns from labeled data (inputs with known answers). Used for classification and regression.

Examples: Spam detection, house price prediction.

![Scaling Data: Before or After Train-Test Split? | by Megha Natarajan | Medium](https://images.openai.com/static-rsc-4/YCLjj8uYmnuOk3QFqM8_SAbvMbF0C2NMzIqYm5biJd7MAQo1zkQCqdd1B8D-CUTy5_Mi0tZq_YVKl2MriFLZCI1Lf0OUs2yXdMHuFNPsJNXjNz5qIVX6t0o8T6qsWGZH_QLzU9cSPdq0IAl_P7IS45qHK9tIrCnCaJoU_m6onx0?purpose=inline)

2. Unsupervised Learning

Finds hidden patterns or groups in data without predefined labels.

Examples: Customer segmentation, clustering.

![Skillsyard](https://images.openai.com/static-rsc-4/A5ry2A1Tcut-126KqwEylfZTbWtDpWtV3D1NOi0bVhKom-6xscsLRCmmLIKer2F1Lz0vNVv9B0R7mkGxLNwymh05HBEAlDYs0UuMlJDwYVCElDCTUYgI3LcztUiXtMeJ0-TEsO7w1INGrP3ipcJtyBDYPYZM6fCQPPr8DIhfWmI?purpose=inline)

3. Reinforcement Learning

An agent learns by interacting with an environment and receiving rewards or penalties.

Examples: Game-playing AI, robot navigation.

![MAE/SimMIM for Pre-Training Like a Masked Language Model | by Akihiro FUJII | Medium](https://images.openai.com/static-rsc-4/CPb0eP5yO_35-tYnQKnPz59T9zd2G96LmMxYu1jNoNX_q-aEGg3JAxpbon5dzCLo57iymtZrpx2OoZF6VPnnLTKKy9pbXB_Odp43ISsEd-CPF-OEpJ9GVrOBorAunc2GhWeh2n6KAlLKINVB66JXM-SS0ivHBH-ZeVIaLxzPSpo?purpose=inline)

4. Self-Supervised Learning

Creates learning signals from the data itself rather than requiring manually labeled examples.

Examples: Language model pretraining, image representation learning.
