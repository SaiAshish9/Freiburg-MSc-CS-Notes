
## . Incorporating Experts' Knowledge

- **Dynamic Fusion:** Merges expert domain knowledge models with data-driven machine learning models into a unified inference system (_Wahl & Amft, 2018_).

## 2. Does AI Add Value? (Human-AI Interaction)

Evaluation of clinical decision accuracy when MDs are supported by AI tools across organ rejection and graft loss prediction endpoints (_Roller et al., 2022_):

|   |   |   |   |   |
|---|---|---|---|---|
|**Clinical Task / Endpoint**|**Junior MDs (Alone)**|**Junior MDs (+ AI)**|**Senior MDs (Alone)**|**Senior MDs (+ AI)**|
|**Rejection**|0.5714|**0.7553**|**0.7134**|0.4870|
|**Graft Loss**|0.8067|**0.8276**|**0.8108**|0.7320|

### Key Takeaways

- **Differential Impact:** AI assistance significantly boosts performance for less experienced clinicians (**Junior MDs**), but can paradoxically degrade performance for experienced clinicians (**Senior MDs**).
- **Core Insight:** Estimation performance does not automatically improve with AI; human-AI workflow and interaction design are crucial.
