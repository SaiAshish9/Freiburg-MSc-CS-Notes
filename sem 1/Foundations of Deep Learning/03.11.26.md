
Logistic Regression is a supervised machine learning algorithm used primarily for classification problems.

It predicts the probability that an input belongs to a particular class.

Despite having regression in its name, it is mainly used for classification, not predicting continuous numerical values.

![[Pasted image 20261103134137.png]]

A Decision Boundary is a line, curve, or surface that separates different classes predicted by a machine learning classification model.

In simple words, it is the boundary that helps a model decide which class a new data point belongs to.

## 1. Example: Logistic Regression

Imagine we are classifying students based on their study hours and whether they pass or fail an exam.
- Class 0: Fail
- Class 1: Pass

The model learns a boundary separating these two classes.
![[Pasted image 20261103134435.png]]

A new student data point:
- Below the boundary → Predicted Fail.
- Above the boundary → Predicted Pass.
